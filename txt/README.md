# Чистый комплект v0.6.3 для другого компьютера

Скачайте **[Fuel_Field_Pilot_0.6.3_IDLE_TXT.zip](Fuel_Field_Pilot_0.6.3_IDLE_TXT.zip)**
(на странице файла GitHub — **Download raw file**). В архиве весь необходимый
Python-код в TXT, зависимости и восстановление для IDLE. Примеры, проекты,
документационные папки, тесты и временные файлы исключены.

1. Распакуйте архив. Установите Python 3.12 или новее.
2. В IDLE создайте файл, вставьте текст `ВОССТАНОВИТЬ_ПРОГРАММУ.txt` и сохраните
   как `restore.py` рядом с папкой `code`. Нажмите F5.
3. Выполните напечатанную команду установки зависимостей в PowerShell/терминале.
4. Откройте полученный `Fuel_Field_Pilot_0.6.3/main.py` в IDLE и нажмите F5.

Для ручного копирования доступны также отдельные [TXT-исходники](code),
[восстановитель](ВОССТАНОВИТЬ_ПРОГРАММУ.txt) и [зависимости](requirements.txt).
Структуру папок нужно сохранить; у Python-файлов удаляется только последнее `.txt`.
Три инструкции встроены в Python-модуль, поэтому кнопки справки работают без `docs`.
Схемы с сеткой и стрелками также встроены в код справки, дополнительных файлов
из репозитория для их отображения не требуется.

Восстановитель проверяет SHA-256 всех исходников до записи и отказывается
перезаписывать изменённую установленную копию. Точный исходный Git commit указан
внутри него. Linux-восстановление и открытие всех трёх справок проверяются тестом;
Windows/Spyder отдельно не проверялись по ранее согласованному ограничению.

Архивы 0.5.2, 0.6.1 и 0.6.2 оставлены для истории. Для текущих исправлений нужен **0.6.3**.
Пакет воспроизводится командой `python -B tools/package_txt.py` после commit кода.
