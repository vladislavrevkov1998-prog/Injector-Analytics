# Чистый комплект v0.8.4 для другого компьютера

Скачайте **[Fuel_Field_Pilot_0.8.4_IDLE_TXT.zip](Fuel_Field_Pilot_0.8.4_IDLE_TXT.zip)**
(на странице GitHub — **Download raw file**). Архив содержит весь необходимый
Python-код в TXT, зависимости и восстановитель для IDLE.

1. Установите Python 3.12 или новее и распакуйте весь архив.
2. В IDLE вставьте текст `ВОССТАНОВИТЬ_ПРОГРАММУ.txt` в новый файл и сохраните
   как `restore.py` рядом с папкой `code`. Нажмите F5.
3. Выполните напечатанную команду установки зависимостей в PowerShell/терминале.
4. Откройте восстановленный `Fuel_Field_Pilot_0.8.4/main.py` в IDLE и нажмите F5.

Для ручного копирования доступны [TXT-исходники](code),
[восстановитель](ВОССТАНОВИТЬ_ПРОГРАММУ.txt) и [зависимости](requirements.txt).
У Python-файлов удаляется только последнее `.txt`, структура папок сохраняется.
Семь инструкций и пять схем встроены в Python-модуль; справка работает без `docs`.
Пользовательские проекты загружаются отдельно. Примеры, тесты, проекты и
временные файлы в архив не входят. Зависимости устанавливаются через интернет;
интерпретатор Python в архиве отсутствует.

В v0.8 на вкладке 04 откройте «Баланс воздуха…», введите свои расходы и L0,
включите воздух и примените изменения. Воздушные матрицы и расходный α доступны
после расчёта топлива. Старые проекты открываются с отключённым воздухом.
[Инструкция и ограничения модели](../docs/V0.8_GUIDE.md).

Восстановитель проверяет SHA-256 всех файлов до первой записи, допускает
повторный запуск и отказывается перезаписывать изменённую установленную копию.
