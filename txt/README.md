# Чистый комплект v0.7.0 для другого компьютера

Скачайте **[Fuel_Field_Pilot_0.7.0_IDLE_TXT.zip](Fuel_Field_Pilot_0.7.0_IDLE_TXT.zip)**
(на странице файла GitHub — **Download raw file**). В архиве весь необходимый
Python-код в TXT, зависимости и восстановитель для IDLE. Примеры, проекты,
папки документации, тесты и временные файлы исключены.

1. Распакуйте архив. Установите Python 3.12 или новее.
2. В IDLE создайте файл, вставьте текст `ВОССТАНОВИТЬ_ПРОГРАММУ.txt` и сохраните
   как `restore.py` рядом с папкой `code`. Нажмите F5.
3. Выполните напечатанную команду установки зависимостей в PowerShell/терминале.
4. Откройте полученный `Fuel_Field_Pilot_0.7.0/main.py` в IDLE и нажмите F5.

Для ручного копирования доступны [TXT-исходники](code),
[восстановитель](ВОССТАНОВИТЬ_ПРОГРАММУ.txt) и [зависимости](requirements.txt).
Сохраняйте структуру папок; у Python-файлов удаляется только последнее `.txt`.
Пять инструкций и пять схем встроены в Python-модуль: справка работает без `docs`.
Новая модель выбирается через «Настройки → Перенос топлива внутри ЖТ…»;
физические параметры задаются явно, учебный пресет помечен как синтетический.

Восстановитель проверяет SHA-256 всех входов до записи и отказывается
перезаписывать изменённую установленную копию. Повторное восстановление
не меняет файлы. Существующие проекты загружаются отдельно, в архив они не входят.
Windows/Spyder отдельно не проверялись по прежнему указанию пользователя.

Исходный commit: `93d712a05ef0f0c3361deec36e3f9596f9c7d0cd`.
SHA-256 ZIP: `b3a6c6272187bb261b0b386aa4e3601b89bb7ebc9664c71ffd64bfc202abc912`.

Проверен именно этот ZIP: 51 элемент, 49 восстановленных файлов, 46 runtime-
модулей побайтно совпали с репозиторием. В отдельной папке с кириллицей
запустились Qt-интерфейс, все пять инструкций/картинок и инерционный расчёт
с балансом массы (`PORTABLE_V07_OK`).

Старые архивы оставлены для истории. Для текущей версии нужен **0.7.0**.
Сборка воспроизводится `python -B tools/package_txt.py` из чистого коммита
исходников; точный commit каждой сборки записывается в восстановитель.
