# Пояснения к параметрам существующей v0.1.2 и проектируемой модели

**Актуально для исходного кода v0.1.2; спецификация v0.2 меняет семантику только там, где отдельно указано.**

| Параметр | Текущее назначение в core.py | Когда учитывается |
|---|---|---|
| `rc0_mm` | Средний радиус стартового кольца | Все модели геометрии |
| `h0_mm` | Начальная полная ширина кольца (в т.ч. FWHM для гауссовой модели) | Все модели |
| `alpha_deg` | Полный угол конуса максимума кольца, `Rc(z)=Rc0+z·tan(alpha/2)` | Все геометрические модели, кроме `two_angles` |
| `z_ref_mm` | Масштаб расстояния в степенном законе толщины `h=h0(1+z/z_ref)^power`; это **не положение одного из 4 сечений** | Только `power` |
| `inner_angle_deg` | `Rinner(z)=Rc0-h0/2+z·tan(alpha_inner)` | Только `two_angles` |
| `outer_angle_deg` | `Router(z)=Rc0+h0/2+z·tan(alpha_outer)` | Только `two_angles` |
| `clock_deg` | Постоянный угловой поворот измеренной 36-секторной эпюры относительно ориентации форсунки | Все угловые модели |
| `rotation_deg_per_mm` (ω) | Дополнительный поворот эпюры `ω·z` по удалению от сопла; **не угловая скорость во времени** | Все угловые модели |
| `decay_length_mm` | Масштаб линейного и экспоненциального уменьшения угловой неравномерности | `linear`, `exponential` |
| `diffusion_deg_sqrt_mm` (σ) | Угловое размытие `sigma_phi(z)=sigma*sqrt(z)`; размерность град/√мм | `diffusion` |

Текущая ориентация сектора 1 для nozzle j: `theta_j + (180° if outer else 0°) + Clock_j + ω_j*z`, отсчёт CCW от глобального +X.

В v0.2 перейти на наружный радиус сопла/плёнки `R_сопла` с начальным диапазоном `[R_сопла-h0, R_сопла]`. Миграция `R_сопла = old_Rc0 + old_h0/2`.

**Важная интерпретация `two_angles`:** обе величины влияют на РАДИАЛЬНЫЕ границы локального кольца. Для расходящегося внутри-внешнего кольца возможно `inner_angle<0`, `outer_angle>0`; при этом геометрию нужно валидировать, иначе границы могут пересечься. Величины не задают две независимые физические траектории струй без калибровки.

**Скорость топлива:** текущая программа распределяет заданный mass flow по контрольным площадкам; без скорости нельзя получить `ρ_fuel_in_volume` или мгновенный объём топлива в ячейке. `Vcell = mdot_cell*duration/rho` — интегральный прошедший за интервал объём, не объём жидкости, находящийся в газовом тракте в конкретный момент.
