## Расходы и совместимость

- Источники: manual (измерение), sectors (оценка), curve (характеристика).
  Канонический расход — кг/ч, внутренний массовый поток — кг/с.
- Давление ручного измерения и давление секторов хранятся отдельно.
  При новом пересчёте расход масштабируется Q(target)/Q(reference);
  sectors использует ΣV·10⁻⁶ρ/(Tη). Значения измерений не перезаписываются.
- При неизвестной полноте сбора явно сообщается η=1. Экстраполяция запрещена
  по умолчанию; opt-in даёт предупреждение и видимый статус. Нулевая опорная
  Q, отсутствующая характеристика и отрицательная экстраполяция отклоняются.
- Один экспериментальный пункт допустим как измерение; новый наклон/расход
  между неизвестными давлениями не выдумывается. Точки могут быть немонотонны.
- Старые JSON получают Legacy-режим: прежний sectors-расход сохраняется без
  скрытого пересчёта 2,5→30. Новый проект GUI начинает в calibrated-режиме.
- Формат `fuel-field-pilot-v1` сохранён с дополнительным `version: "0.2"`.
  Старые отсутствующие поля имеют значения по умолчанию. Для R_сопла:
  R_сопла=old_Rc0+h0/2; исходный Rc0 сохраняется как внутреннее legacy-поле.
  Несогласованные R_сопла/Rc0 отклоняются. Старое приложение не обязано читать
  новый JSON с дополнительными полями.
- Шаблоны меняют только унаследованные параметры; индивидуальные overrides
  переживают смену шаблона. Reset восстанавливает наследование. Демонстрационные
  начальные шаблоны двух типов одинаковы, пользователь редактирует их независимо.
- Проект сохраняет 140 уникальных ID и принадлежность 1–70 наружному,
  71–140 внутреннему ряду. Порядок объектов JSON не подменяет их ID.
  Auto-follow сохраняет расстояния и меняет только текущую/следующие позиции
  своего ряда, включая отключённые. Само отключение не перемещает соседей.

## Проверки

Среда: Linux, Python 3.12, NumPy 2.5.4, Matplotlib 3.11.2, PyQt5 5.15.11.
Перед изменениями прошли 52 теста. Полный финальный набор: **80 тестов, все
прошли, 0 пропусков**. Время указано в выводе unittest текущего запуска.

```bash
QT_QPA_PLATFORM=offscreen MPLCONFIGDIR=/tmp/injector-mpl \
 /workspace/.venvs/injector-analytics/bin/python -B -m unittest discover -s tests -v
```

Проверены:

- точные измеренные точки, интерполяция/экстраполяция, валидация NaN, дубликатов,
  давлений и единиц, повреждённого XLSX, выбор одного из нескольких листов;
- известная кривая Q(30)/Q(2.5)=12, η, сохранение независимого измерения;
- баланс четырёх сечений в новых режимах, неизменность числового CSV от шкалы;
- все четыре матрицы старого проекта против результатов исходной v0.1.2
  (rtol=1e-12, atol=1e-15), миграция, ссылки и обратное открытие нового JSON;
- создание типа, назначение, защита удаления, изменение точек, смена единиц
  и плотности, шаблоны/reset/overrides, auto-follow, Undo/Redo;
- реальный QThread-расчёт после сохранения и открытия JSON с тремя источниками
  расхода, MathText, одиночное превью, кэш и отрисовка неактивных видов для PNG.

Пакетный запуск `batch_run.py examples/demo_project_v02.json` создал и проверил
**16 PNG и количественный CSV**. Введено 1614.624 кг/ч; максимальная абсолютная
относительная невязка четырёх сечений **6.931×10⁻¹⁵**. Демонстрационные значения
не являются верификацией характеристик реальных распылителей.

## Верификация Дитякина: результат исследования

Получена и прочитана статья Гуракова и соавт. (2021), «Расчёт характеристик
течения жидкого топлива при его подаче через центробежные форсунки малоразмерных
газотурбинных двигателей», Вестник Самарского университета, т.20 №2, с.19–35,
DOI **10.18287/2541-7533-2021-20-2-19-35**.

Рабочая ссылка после перенаправления:
https://journals.ssau.ru/vestnik/ru/article/download/8927/8330

SHA-256 полученного PDF:
`8c8709609ac2208ba2017a05a3c52673ca6d9c4806afb4e99d1e82cdb5e476d6`.

На с.23 (страница 5 PDF) визуально проверены:

- заполнение сопла φc = 1−((rc−tпл)/rc)²;
- формула (3): μL = 1/√(Aₑ²/(1−φc) + 1/φc² + Δs).

Там же авторы отсылают вычисление Aₑ, связанного φc и потерь Δs к ссылкам
[4;5]. Книга [5]: Дитякин Ю.Ф., Клячко Л.А., Новиков Б.В., Ягодкин В.И.
**«Распыливание жидкостей», Машиностроение, 1977, 207 с.**

В этой статье нет полного воспроизводимого алгоритма вычисления Aₑ и потерь
из геометрии, вязкости и режима. Факт наличия (3) не подтверждает отсутствующие
коэффициенты, алгоритм и диапазоны применимости. Предоставленная ссылка
`https://ingc.ru/upload/iblock/255/kafgqmdqmwfredrjxdr0t3d7ev60hiy0.pdf` после
открытия сетевого доступа возвращает **HTTP 404**; поиск по сайту не нашёл
Дитякина. Две связанные публикации журнала (3320, 6387) описывают моделирование
течения/взаимодействия, полного алгоритма Дитякина в них также не найдено.

Расчётный пункт редактора поэтому отключён с явным сообщением. Постоянная μ
или произвольно выбранные потери не подставляются. Тейлор не добавлен.

Для полного релиза нужен оригинал/доступный источник процедуры Aₑ, φc, Δs,
с геометрическими определениями, коэффициентами, единицами, применимостью
и контрольным примером. После получения источника остаются реализация этого
режима, независимые расчётные проверки и согласование проверенной методики,
как требует `CODEX_START.md`.
