# Квазистационарный режим: давление по шагам обхода

## Результат и связь со стационарным расчётом

Режим встроен в **«Рассчитать сечения» (F5) на вкладке 04**. Он использует геометрию, форсунки и расходные характеристики проекта, но вместо одного целевого перепада использует давление своего коллектора на каждом временном шаге. Температуры, давление воздуха на входе и отдельная «измерительная сессия» не требуются.

Результат — накопленная **матрица плотности массового расхода** для каждого заданного z. На шаге 0 рассчитываются все радиальные ячейки углового столбца первого положения; на шаге 1 — следующего положения и т.д. Эпюры на 04 строятся из этих матриц. «Накопленная» означает собранную по шагам картину: q остаётся в кг/(м²·с), не суммируется во времени и не умножается на длительность шага.

Поле орошения нельзя склеивать из разных времён. Поэтому «Подробное суммарное поле» показывает **полное мгновенное поле** при выбранном шаге. Ползунок внизу поля перебирает исходные времена характеристики давления. Он не изменяет уже накопленную матрицу или её эпюры.

## Быстрый запуск на пользовательском проекте

1. Через меню «Проект» откройте `examples/demo_project_user_field.json`. Исходный файл не меняйте: при необходимости сохраняйте проект под новым именем.
2. Откройте «Настройки → Испытания и расстановка» или шестерёнку на 02. Установите галочку **«Квазистационарный»** — откроется окно настройки режима. Его также можно открыть кнопкой напротив галочки.
3. Нажмите «Загрузить *.quasi.json» и выберите `examples/demo_user_field_140_two_collectors.quasi.json`.
4. В примере 140 шагов с Δt=0.5 с, два коллектора A/B и **синтетические давления**, не записи испытаний. Включённый флажок применения привязок назначает ID 1–70 коллектору A, ID 71–140 — B. Эти демонстрационные привязки не утверждают реальное подключение изделия. Проверьте их в соответствии с испытанием.
5. Нажмите **«Применить»**. Привязки появятся в столбце **«Коллектор» на 02**. Выполните F5 на 04.
6. Матрица и окружные эпюры теперь учитывают пульсации давления. В подробном поле двигайте нижний ползунок: шаги 0…139, времена 0…69.5 с. Последнее положение гребёнки — 357.428571°, отдельной повторной точки 360° нет.
7. При снятии галочки F5 снова выполняет исходный стационарный расчёт v0.4.1. Настройки давления и привязки сохраняются; повторное включение их восстанавливает. Ctrl+S сохраняет режим, настройки и привязки в JSON проекта.

## Параметры окна режима

| Поле | Значение |
|---|---|
| Шагов | Равно числу окружных ячеек сетки на 01. Сетка 6×140 означает 140 шагов и одновременный расчёт шести радиальных ячеек на каждом шаге. При другом числе радиальных уровней рассчитываются все заданные уровни. |
| t₀, с | Время первого измерения в общей шкале времени. |
| Δt, с | Постоянный положительный интервал между измерениями. `tᵢ=t₀+i·Δt`. Это не окно усреднения: давление строки считается фактическим целевым перепадом в данный момент. |
| Первый угол, ° | Положение гребёнки на шаге 0. Обычно 0°. Должно совпадать с одним из центров окружной сетки на 01; разрешён циклический сдвиг на целое число ячеек. |
| Обход | Против ЧС или по ЧС. `θᵢ=(θ₀+s·i·360/N) mod 360`, s=+1/−1. Меняет соответствие времени угловому столбцу, но не перемещает форсунки и не меняет нумерацию их 36 секторов. |
| Общий коллектор | Канал для форсунок с пустым значением «Коллектор» на 02. Обычно A. Имена должны совпадать, включая регистр. |

Число шагов в загруженном файле должно совпадать с окружной сеткой проекта. Приложение не обрезает, не растягивает и не интерполирует данные молча. При изменении сетки подготовьте характеристику с соответствующим числом строк. Углы и время первых трёх столбцов защищены от ручной правки и выводятся из параметров режима.

## Таблица коллекторов

Одна строка — один коллектор. Можно добавлять, удалять и переименовывать коллекторы. После изменения состава/вида нажмите «Обновить колонки давления».

| Столбец | Что указать |
|---|---|
| Коллектор | Уникальное имя, например A или B. Это имя выбирается у каждой форсунки на 02. |
| Единицы топлива/Δp | `kgf/cm2` (кгс/см²), `bar`, `Pa`, `kPa`, `MPa`. Все давления данного столбца имеют эти единицы. |
| Вид давления | `delta_p`: уже измеренный перепад топлива относительно газа; `p_fuel_abs`: абсолютное топливо; `p_fuel_gauge`: избыточное топливо. В редакторе ячейки доступны понятные подписи. |
| Единицы газа | Используются только для абсолютного/избыточного топлива. Могут отличаться от единиц топлива; перед вычитанием выполняется конверсия. |
| Общая база gauge (reference_id) | Для избыточного топлива/газа обязательное имя общего нуля измерения, например `atm_test_01`. Вы тем самым явно подтверждаете согласованную базу пары. Для Δp и абсолютной пары можно оставить пустым. |

**Давление воздуха на входе в КС не подставляется вместо газового противодавления форсунки.** Если в таблице уже задан физический Δp, выберите `delta_p`; газовый ряд тогда не нужен и второй раз не вычитается. При `p_fuel_abs` газовая колонка содержит абсолютное давление среды у выхода форсунки; при `p_fuel_gauge` — избыточное давление в той же базе. Физический перепад на каждом шаге: Δp=Pтопл−Pгаз>0.

## Таблица давления по шагам

| Ячейки | Что вводить |
|---|---|
| Шаг / t, с / Угол гребёнки, ° | Автоматические, защищённые. Индекс шага начинается с 0 и не является ID форсунки. |
| A · давление, B · давление и т.д. | Значение давления соответствующего коллектора в его единицах и физическом виде для данной строки времени. Вводите число без приписанной единицы; точка и запятая допустимы. |
| A · газ, B · газ и т.д. | Появляются только при задании давления топлива относительно абсолютной/избыточной базы. Требуется значение на каждом шаге, в единицах газа этой строки коллектора. |

Заполните все шаги каждого заданного коллектора. Неполные/неконечные давления и Δp≤0 диагностируются. Пропуски не становятся нулями и не интерполируются. Допускается вставка числовых столбцов из Excel в уже созданные строки.

**Справа от таблицы — график каждого коллектора.** Ось X показывает время в
секундах, ось Y — давление в единице коллектора. Для готового перепада показана
Δp; для абсолютного/избыточного топлива показаны топливо, газ (переведённый в ту
же единицу) и полученный перепад. Графики обновляются после ввода, вставки и
импорта; неприменённый черновик можно проверить визуально. Ошибочные/пустые
значения образуют разрывы, а не нулевые измерения. Для большого числа
коллекторов доступна вертикальная прокрутка; ширина таблицы и графиков меняется
перетаскиванием разделителя. Изменение графика не запускает основной расчёт.

Для каждой включённой форсунки должен существовать используемый канал давления. Привязка в столбце «Коллектор» на 02 — источник истины. Пустое значение означает общий коллектор; выключенные форсунки сохраняют ID/геометрию и дают нулевой вклад. Соседние ячейки могут получать вклад форсунок из обоих коллекторов одновременно: программа суммирует все пространственные влияния, а не назначает ячейке один «свой» источник.

## Импорт XLSX/CSV

Нажмите «Импорт XLSX / CSV». Первая строка листа должна содержать уникальные заголовки; ниже — ровно N строк. Выберите лист, столбец времени (если он есть), единицу времени и столбец давления каждого загружаемого коллектора. Для абсолютной/избыточной пары выберите также газ. Названия столбцов произвольны: сопоставление задаётся явно.

Простой формат для двух перепадов: `step, t_s, A, B`. Для 140 шагов импортируются ровно 140 строк. Никакая температура не нужна. Пример XLSX/CSV: `demo_user_field_140_two_collectors_pressure.xlsx` / `.csv` в `examples`; его единицы — kgf/cm2, все числа синтетические.

Если выбран временной столбец, проверяется постоянство положительного шага. Флаг «Принять начало и постоянный шаг времени из файла» переносит t₀/Δt в настройки. Если флаг снят, времена должны совпасть с настройками. Без временного столбца используется порядок строк и заданные t₀/Δt. Не выбирайте столбец номера шага как секунды, если Δt не равен 1 с. Календарные строки дат предварительно преобразуйте в числовое время; числа суток Excel переводятся выбранной единицей.

Единицы давления задаются в таблице коллекторов **до импорта**, а не угадываются по числам. Коллекторы с «Не загружать» сохраняют прежние значения. Сырые строки, SHA256 файла и сопоставления сохраняются в метаданных настроек; исходный файл не перезаписывается.

## Сохранение и применение

- **Применить** переносит подготовленные настройки в текущий проект. Если загруженный файл содержит привязки и соответствующий флажок включён, одновременно обновляются коллекторы на 02. Это одна операция Undo/Redo. Расчёт запускается отдельно F5.
- **Закрыть** без применения не переносит изменения черновика в проект.
- **Сохранить *.quasi.json** создаёт отдельный переносимый файл настроек и текущих/подготовленных привязок форсунок. Имя обязательно получает окончание `.quasi.json`. Его внутренний формат — `fuel-quasistationary-settings`, отличающийся от `fuel-field-pilot-v1` проекта. Сохранение отдельного файла не включает режим и не заменяет основной проект.
- **Загрузить *.quasi.json** меняет черновик окна. Привязки из файла применяются только по флажку и кнопке «Применить»; их количество по коллекторам показано в сообщении. Для загрузки проекта используется меню «Проект», для настроек — это окно. Перепутанные форматы отклоняются.
- **Ctrl+S** после применения сохраняет основной проект, выбранный режим, настройки и привязки. Переключение стационарный/квазистационарный не стирает характеристику.

## Как строится матрица и поле

Геометрические ядра K фиксированы на весь обход. На шаге i для каждой форсунки j вычисляется Gⱼ(tᵢ) из её собственного коллектора, затем суммируются вклады в соответствующий угловой столбец:

`q[r, column(i), z] = Σⱼ W[r, column(i), j, z] · Gⱼ(tᵢ)`.

W — консервативные единичные пространственные веса, делённые на площадь ячейки. Они строятся независимо от референсного расхода, в том числе при G_ref=0. В режиме источника `curve` берётся абсолютное Q(Δp) один раз. В `manual/sectors` исходное измерение/оценка при своём опорном давлении умножается на Q(Δpᵢ)/Q(Δp_ref). Методика Дитякина и экспериментальные характеристики используются прежние; скрытый корневой закон не подставляется.

Измеренные Gт, 36 секторных объёмов и геометрия при этом не переписываются. Стационарный флажок «пересчёт по характеристикам» и целевой перепад относятся к стационарному режиму; в квазистационарном перепад каждого шага учитывается всегда. Для секторов сохранена исходная политика полноты сбора проекта. Выход за экспериментальный диапазон Q требует прежнего разрешения экстраполяции; временной экстраполяции здесь нет, поскольку требуется точное число шагов.

Матрица собирается для **каждого z** из списка 01. До индивидуального среза сопла вклад форсунки нулевой. Все радиальные ячейки одного столбца относятся к одному времени. Консервативная матрица и подробное непрерывное поле сохраняют прежнее различие дискретизации v0.4.1.

## Результаты на 04 и ползунок

- **Матрица**: накопленная картина всего обхода с единицами выбранной величины. В её числовом экспорте у каждого столбца есть шаг, время и давления коллекторов.
- **Окружные эпюры**: значения из этой накопленной матрицы. Замыкание линии в 360° — только оформление, не дополнительный временной шаг.
- **Подробное суммарное поле**: полное поле при одном времени. Нижний ползунок имеет ровно N положений исходной характеристики. Подпись показывает шаг, время, положение гребёнки, Δp коллекторов и баланс мгновенного сечения. Стрелки клавиатуры перемещают на один шаг. Изменение времени не пересчитывает K и не меняет матрицу.
- **Полярные эпюры форсунок**: прежние относительные формы секторного распыла; это не карта накопленной массы или новая температурная модель.

Массовый баланс проверяется отдельно для каждого полного мгновенного сечения: подача через достигшие плоскости сопла = внутри тракта + за внутренней стенкой + за наружной стенкой. **Для матрицы из разных времён единого мгновенного глобального баланса нет.** Малая невязка подтверждает численное сохранение массы, а не экспериментальную точность модели.

Auto-шкала подробного квазистационарного поля фиксирована по времени: верхняя граница берётся из огибающей максимальных расходов форсунок. Это сохраняет визуальную сопоставимость кадров; при «общей шкале всех z» используется общий предел. Manual/Saturate/Clip работают по прежним правилам и не меняют численные матрицы. Кэш изображения позволяет менять интенсивность без перестроения осей и всех подписей форсунок.

При движении ползунка меняются **интенсивности** поля. Контуры форсунок и форма
их ядер остаются на своих местах. При небольших колебаниях Δp различие яркости
может быть небольшим: под полем показаны фактические давления, расход и его
изменение относительно шага 0. Для демонстрационного файла сравните шаги
**0 и 35**; на шагах 0 и 70 давления примера совпадают, поэтому поля тоже
совпадают. Если Manual/Saturate скрывает различия насыщенным цветом, выберите
Auto или подходящий диапазон Manual. Данные при этом не нормируются отдельно
для каждого кадра и не усиливаются искусственно.

В JSON-сравнении накопленная матрица/эпюры учитывают режим загруженного проекта; подробное поле сравнения показывает явно подписанный шаг 0. Внешние XLSX/CSV по-прежнему можно загружать как независимые графики. Идентификация параметров v0.4.1 использует стационарное ядро: для неё нужно выбрать стационарный режим, сохранив настройки квазистационарного.

## Экспорт и проверка

XLSX на 04 содержит накопленные эпюры всех z со временем/шагом/давлениями, лист `Pressure_flows` со 140 расходами на шаг, `Instant_balances` для всех z/шагов и `Metadata` со снимком проекта/настроек и методами расчёта. CSV содержит матрицы со временем, дополнительные таблицы расходов/балансов и JSON-манифест; сохраняйте комплект целиком. PNG подробного поля соответствует выбранному ползунком времени. JSON проекта/режима сохраняет входы; после открытия вычисления повторяются F5.

При проверке сначала сверяйте N, часы/Δt, угол/направление, единицы и физический вид давления, привязки на 02, диапазоны Q и исходные давления измерений. Постоянные перепады должны воспроизводить соответствующий стационарный режим при тех же координатах и правилах расхода. При пульсациях проверьте отдельные столбцы и мгновенные снимки. Нулевая задержка и неизменная форма K — текущие допущения; воздух, коэффициент избытка и температура остаются задачами следующих согласованных версий.
