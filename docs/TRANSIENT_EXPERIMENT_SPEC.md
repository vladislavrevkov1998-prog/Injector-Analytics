# Квазистационарный расчёт при последовательном окружном сканировании — v0.5

Статус: согласованное ТЗ. Реализация v0.5 описана в [инструкции](V0.5_GUIDE.md), проверки — в [Validation](V0.5_VALIDATION.md). Исходные наблюдения температуры на выходе КС не превращаются в модель температуры.

## 1. Геометрия и время измерения

Протокол пользователя: датчик/гребёнка в окружном положении `θ_i`, где одновременно измеряется температура в **6 радиальных точках** (на высоте тракта); затем датчик перемещают примерно на `1/140` окружности, выполняют новый шестиканальный замер, пока не измерят до 140 положений. Поэтому `T[6,140]` имеет **временную развёртку по второму индексу**: при одном i время для шести радиальных точек одинаковое (или имеются паспортные индивидуальные задержки регистрации), между разными i — другое.

`θ_i = (θ_start + s·i·360/N_angle) mod 360`, где `s=+1/-1`, `N_angle=140` по умолчанию; реальный `θ_i` может быть задан вместо номинального. `i` — **номер положения измерения**, не ID форсунки. Отдельно сохранять радиус каждого датчика и физический z-план измерения.

Нельзя предполагать одновременную регистрацию всех 840 температур, переставлять измерения по углу без изменения их привязки ко времени или усреднять весь протокол до одного давления.

## 2. Давление и расход

Входной ряд: `{timestamp_s, P_measured, unit, manifold_id}`. Явно указывать, измерено:
- `delta_p` (перепад топлива относительно местного газового давления),
- или `p_fuel_abs` / `p_fuel_gauge` и отдельно опорное `p_gas` с согласованными базами давления.

В пересчёте использовать **перепад** `Δp_j(t)=p_fuel,j(t)-p_gas,j(t)`. Поддержать несколько коллекторов через `nozzle_id -> manifold_id`, при одном коллекторе — настройка по умолчанию. Не отождествлять давления разных коллекторов. Валидация на Δp>0 и диапазоны применимости расходных характеристик.

Базовая модель на временном шаге t:
`G_j(t)=G_j,ref * Q_type,j(Δp_j(t))/Q_type,j(Δp_ref,j)`
с сохранением режима источника `manual/sectors/curve` и различием: `curve` уже вычисляет абсолютный G по Q(Δp); повторное масштабирование **недопустимо**. Реализовать это внутри функции `flow_at_pressure(nozzle,settings,Δp)`, которую проверяют независимые тесты против существующей `flow_status`.

Если референсного расхода, типа распылителя, кривой или валидного давления нет, выдавать понятную ошибку или явно помеченный статус «невозможно оценить»; **не подставлять sqrt(Δp) молча**. Выход за измеренные точки характеристик — только по существующему разрешению экстраполяции с явным статусом.

## 3. Квазистационарная пространственная модель

Зафиксировать аналитическую геометрию и ориентацию форсунки на каждом выбранном z на весь измерительный протокол, т.е. первый режим **без зависимости K от давления**:
`q_f(P,z,t)=Σ_j G_j(t)·K_j(P,z)`, `∫_{всей плоскости} K_j(P,z)dA=1`.
Учитывать границы кольцевого тракта и внепроточные потоки; распределение между соседями определяется наложением K автоматически.

Для каждого измерительного углового положения `i` с окном `[t_i0,t_i1]` и радиальным датчиком `r`:
`<q>_{ri} = (1/(t_i1-t_i0)) ∫_{t_i0}^{t_i1} [Σ_j G_j(t)K_j(P_{ri},z)] dt`.
Это **средняя плотность массового расхода через заданную площадку/контрольный элемент**, а не объёмная концентрация топлива. Выбрать и документировать:
- `P_{ri}` — координата/центр ячейки, тогда оценивается q как плотность в центре;
- либо footprint реального датчика: `W_{ri,j} = (1/A_ri)∫_{A_ri} K_j(P,z)dA`.
Не называть «расходом через точку» интегрируемое по площадке значение.

При постоянном K можно предварительно сформировать матрицу влияния `W[measurement_cell,j]`, затем вычислять `q(t)=W·G(t)`. Для существующей матрицы ячеек `W` строить из консервативных весов до их умножения на референсный расход (избегать деления на G_ref=0). Зафиксировать проверку суммы пространственных весов с внутренней/внешней стенками.

## 4. Интегрирование по времени и задержка

- Временные окна должны задаваться как полуинтервалы `[start,end)` (кроме финальной точной границы при необходимости). Проверить согласованность единиц времени и часов приборов, несовпадения датчиков, пропуски и несортированные времена.
- Для базовой модели `τ=0`; это предположение «поле мгновенно следует за давлением». Не заявлять, что топливо, введённое в 1–5 с, непременно проходит контрольную площадку именно в 1–5 с.
- Опционально задать `τ_j(P,z)` из независимого измерения/CFD/эмпирической оценки, тогда `q(P,z,t)=Σ_j G_j(t−τ_j)K_j(P,z)`. Если τ не задана или выход времени за данные, явно указать ограничение; **не оценивать задержку из геометрии без скоростей**.
- Для давления на интервале: численно интегрировать `Q(Δp(t))`, а не вычислять Q только по среднему давлению (Q нелинейно); сохранять способ интерполяции и метод quadrature.
- Время отклика термопары и время пролёта топлива — **два разных механизма**; отклик температуры хранить в метаданных, но **не корректировать** без отдельной измерительной модели.

## 5. Исходные и выходные данные

`MeasurementSession` с версиями данных:
- схема (направление обхода, первый θ, количество остановок), фактические θ_i и radius_r;
- для каждой остановки t_start/t_end, 6 температур и optional flags;
- таблица давления с channel/manifold_id, baseline/units, временные метки;
- дата/описание испытания, источники файла, uncertainty и sampling_method.

Выходные массивы: `T_measured[radial,step]`, `Q_fuel_corrected[radial,step]`, `Δp_window`, `G_nozzle_window[step,140]`, optional `W`, статусы, паспорт режима. Отображать топлива и температуру на **разных осях** и с разными единицами, без автоматической фитинговой связи. Экспорт отдельных данных и манифеста расчёта в CSV/XLSX, сохранять исходные временные ряды неизменными.

Для проверки истинного поля при одном t можно дополнительно вывести временной снимок всех ячеек и проверить: `Σ_j G_j(t) = inside+inner+outer`. Для составленной из **разных временных окон** матрицы `[radial,step]` единый мгновенный глобальный массовый баланс **не определён** — не показывать его как баланс стационарного сечения.

## 6. Минимальные тесты

1. Все давления постоянны: `flow_at_pressure` и поля совпадают с стационарными расчётами для того же z и координат/footprint.
2. Два времени одинакового угла с разным давлением: q различается согласно Q_type; изменение общего давления без учёта газового перепада не трактуется как изменение Δp.
3. Один угловой шаг — шесть каналов с одним окном; следующий — другой временной интервал. Перемена углового порядка не переставляет значения давления ошибочно.
4. Группы форсунок на разных коллекторах получают разные расходы; массовый баланс замкнут **для каждого мгновенного поля**.
5. Ошибки отсутствующих давлений, экстраполяции, отрицательного Δp, дублирующихся timestamps и непокрытых окон диагностируются.
6. Для временного усреднения нелинейной расходной характеристики средний G не равен (в общем случае) G от среднего Δp; проверка по аналитическому или эталонному ряду.
7. Исторический проект без MeasurementSession остаётся открываемым и не меняет стационарные результаты.
