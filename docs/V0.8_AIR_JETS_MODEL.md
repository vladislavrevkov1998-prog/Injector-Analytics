# v0.8 — расчётная модель воздуха, направленных струй и матриц α

**Статус: проект математического замыкания для Codex, не доказанная физическая модель.** Область: установившаяся / квазистационарная КС ГТД, кольцевая двухрядная многофорсуночная схема; результат — поля **через поперечные сечения** `z_k`, а не полноценный CFD-пересчёт объёма. Здесь отделены **положения из методики Диденко** и **наше расширение**. Код обязан документировать выбранные коэффициенты и основания для их значений.

## B. Система координат и разрешённые величины

Использовать уже существующее `z=x [мм]`, глобальный `θ` от `+X` против часовой стрелки (с отдельным преобразованием измерительного угла), `r` от оси КС. Вектор направления хранить в локальном ортонормированном базисе `(e_z,e_r,e_theta)`; для сопряжений и вычисления расстояний переводить в глобальные декартовы `(z,x,y)` с явными преобразованиями:

```text
e_r(θ) = (0, cos θ, sin θ)
e_θ(θ) = (0, −sin θ, cos θ)
e_z    = (1, 0, 0)
d_global = d_z*e_z + d_r*e_r(θ) + d_θ*e_θ(θ), ||d||=1
```

Для источника на внутренней стенке нормаль в сторону тракта в общем направлена к увеличению `r`, на наружной — к уменьшению `r`; при наклонных стенках учитывать **аналитическую местную нормаль меридионального профиля**, а не просто `±e_r`. Проверять знак введённой ориентации к объёму. `penetration_factor=P≥0` — **безразмерный эмпирический коэффициент**. Геометрические единицы всегда преобразуются `мм↔м` явно. Ключевые расходы в `кг/с`; площади `м²`, `L0` в `кг воздуха/кг топлива`.

Нельзя смешивать:
- `G_air_cell` [кг/с] — осевой расход через ячейку;
- `q_air_cell=G_air_cell/A_cell` [кг/(м²·с)] — плотность расхода;
- `m_air_cell` [кг] — масса воздуха, находящаяся в объёме. **Последняя пока не рассчитывается**;
- `P` — эмпирическая способность отклонять/проникать, **не** скорость `м/с`, импульс `Н` или давление `Па`.

В геометрии с равновысотными радиальными поясами:
`r_j(z)=Rin(z)+j*(Rout(z)-Rin(z))/N_r` и
`A_(j,m)(z) = (Δθ_rad/2)*(r_(j+1)^2-r_j^2)*1e-6` [м²].
При равномерной плотности осевого расхода веса **пропорциональны площади**, не `1/(N_r*N_theta)`.

## C. Задача C1: источники и общий баланс

Реестр:
`AirSource{id,kind,geometry_ref/nozzle_id,z_mm,theta_deg,radius_mm,wall,area_mm2,flow_mode,flow_kg_s,Cd?,direction_local,penetration_factor,entrainment_schedule,spread_radial,spread_angular,provenance,unknown_fields}`.

- `swirler`: отдельный воздушный источник, `nozzle_id` с **индивидуальным** известным расходом. Не экстраполировать общий расход топлива или количество измеренной жидкости на воздух. Возможность отключить/проверить наличие конкретного завихрителя отдельна от флага `enabled` для топлива и связанной сборки; решение явно описать.
- `hole/insert/cooling`: использовать ID и расположение реального геометрического объекта. Для неописанного канала **не создавать физический элемент**; нераспределённый остаток показывать отдельно.
- Стандартный режим `manual`: известные расходы сохраняются неизменными; `area_share`: оставшийся **явно выделенный для распределения** расход делится пропорционально `F`; `effective_area` делится по `Cd*F`, если `Cd` задан; в перспективе по `Δp`. Условие одинаковой массовой скорости через разнородные отверстия при распределении по площадям — **гипотеза с флажком подтверждения**.
- При сумме известных расходных каналов больше полного воздуха **жёсткая ошибка**. При недостающих каналах (или не включённом распределении остатка) существует `G_unassigned`; нельзя добавлять его в матрицу и нельзя объявлять общий баланс всех матричных воздухов равным `G_air_KS`.
- Разделить **воздух, поступивший в ЖТ**, и **воздух, условно вовлечённый в основное смешение**. Граница контрольного объёма и критерий «прошёл данное z» должны быть явно фиксированы.
- Контроль `G_fixed+G_distributed+G_unassigned=G_air_KS`; для каждого источника и z избегать двойного счёта порций вовлечения.

## D. Задача C2: стадийное вовлечение по Диденко

У каждого источника есть `E_s(z)`, доля `[0,1]` включения в смешение к z. Допустить:
- `staged`: список `{z_start_mm,z_end_mm,fraction}`, `fraction≥0`, сумма **ровно 1 в пределах допуска** для полностью вовлечённого источника; контроль порядка и границ ЖТ. Доля может быть вовлечена в несколько следующих участков (пример `0.2/0.2/0.6`);
- `smooth`: сглаженное строго монотонное `E_s(z)` с явной длиной вовлечения;
- `instant`: контрольный предел, вся доля включена сразу при подводе (явно учебный/упрощённый).

Показатели:
```text
G_s,total(z) = поток источника через физическое сечение z (после его ввода)
G_s,mixed(z) = E_s(z)*G_s,total(z)
G_s,core(z)  = (1-E_s(z))*G_s,total(z)
```
Последние два — **распределения одного и того же воздуха по непересекающимся статусам**, а не разные массы. Для `staged` сохранять расходный ledger `source_id↔portion_id↔z`, чтобы второй проход по участку не прибавлял порцию вновь. Если струя не достигла сечения или обратное направление делает «осевой поток» некорректным, **не** назначать `G_s,total=G_s` только потому, что `z>z_source`; сообщить ограничение.

Долевое вовлечение из книги применяется **после** задания абсолютного расхода каждого источника. Его пространственное ядро и направление — наше дополнительное замыкание, которое должно быть отдельно документировано.

## E. Задача C3: пространственное ядро, сохраняющее расход

Пусть `b=(radial_cell,angular_cell)`. Для каждого источника и состояния `q∈{core,mixed}` построить
`W_(s,z,b,q)≥0`, `Σ_b W_(s,z,b,q)=1` по поддержанной проточной области, затем

```text
G_air,total(z,b) = Σ_s [G_s,core(z)*W_s,core(z,b) + G_s,mixed(z)*W_s,mixed(z,b)]
G_air,mixed(z,b) = Σ_s G_s,mixed(z)*W_s,mixed(z,b)
G_air,core(z,b)  = G_air,total(z,b) − G_air,mixed(z,b)
Σ_b G_air,total(z,b) = Σ_s G_s,total(z)
```

Предлагаемые формы, подлежащие проверке Codex:
- Контрольная `uniform`: `W_b=A_b/ΣA`.
- Направленное ядро: вычислять положение центра и ширины влияния в **физических координатах**: по `r` и **периодическому** `θ`, с разумным отсечением по точным стенкам; нормировать интегралы по **площадям ячеек**, а не плотности в центрах. Для узких ядер использовать квантование/численное интегрирование достаточно точное, чтобы не пропадал расход при положении между центрами.
- `film/cooling`: поддерживать отдельное пристеночное ядро вдоль внутренней/наружной стенки, растущее вовлечение; не приписывать пелене условную поперечную струю.
- Если выбрано `spread=0` или центр попадает на границу, поддержать корректный предел через распределение в граничную ячейку/пересечение с площадью; `ΣW=1` обязателен даже при экстремальном параметре.
- Смена `N_r/N_theta` должна уточнять визуальную дискретизацию **без изменения общей массы**; зависимость физических параметров от разрешения не допускается. Выходные `z` пользователь задаёт вручную, вычислительный шаг — внутренний.

## F. Задача C4: эмпирические взаимодействующие векторные струи

**Это наше новое предложение, НЕ готовая формула из Диденко.** Требование пользователя: результирующее направление отдельной струи меняется по мере её продвижения из-за встречных, попутных и пересекающихся **воздушных** струй. Нельзя подменять задачу статическим радиальным «размазыванием».

Каждый источник имеет условную направленную центральную траекторию `x_s(ℓ)` и единичное направление `d_s(ℓ)`, где `ℓ` — длина пути; параметр `P_s` определяет относительную способность проникновения/сопротивления отклонению в явном `reference` масштабе. Для каждой пары `(s,j)` в области перекрытия использовать гладкий неотрицательный вес влияния `K_sj(ℓ)`, зависящий от:
1. расстояния **в метрах** между условными центрами и ширины обоих ядер;
2. угла `arccos(d_s·d_j)` (попутные, встречные, пересечение);
3. относительных расходов и параметров `P_s,P_j` (без домысла о физических импульсах);
4. пространственного перекрытия по `z,r,θ`, причём на кольце `θ=0°` и `360°` соседствуют.

Допустимая **структура** векторной релаксации (не считать единственно правильным законом):
```text
d_s(ℓ+Δℓ) = normalize(d_s(ℓ) + Δℓ*Σ_j K_sj*T_sj)
x_s(ℓ+Δℓ) = x_s(ℓ) + Δℓ*d_s(ℓ+Δℓ)
```
Термины `T_sj` должны быть касательны единичной сфере направлений (`T_sj·d_s=0`) и иметь ясную модельную интерпретацию:
- для почти попутных струй — сближение направления/центра при условном объединении областей смешения, без сложения расхода дважды;
- для пересекающихся — ограниченный направленный разворот и расширение зоны наложения;
- для встречных — контролируемая потеря направленной «пробивности», возможное отклонение в стороны/увеличение ширины, а при идеальной симметрии **не придумывать произвольную ось отклонения** (симметричное расширение или статус «неоднозначная симметрия»).
- `K_sj` имеет необходимую размерность обратной длины при `Δℓ` в метрах, а все входные коэффициенты остаются помеченными как *эмпирические*. Произвольный коэффициент 0/нулевое перекрытие должен приводить к независимым траекториям.

Codex **сначала** должен письменно предложить конкретный математический закон `T_sj,K_sj`, выбрать безопасную и симметричную обработку встречных направлений, затем реализовать и протестировать. Никаких `d=(0,0,0)` или NaN при `d_i=-d_j`. Нужно учитывать взаимное влияние струй, а не однонаправленную последовательную обработку только по списку (проверка перестановки ID!). Для `d_z≤0`, локального разворота/нескольких пересечений `z` выбирать параметризацию по `ℓ` и корректные signed-crossings, либо **явно не поддерживать** расчёт α в затронутых областях; **не** превращать отрицательное движение в положительный осевой расход.

Пределы: такая модель описывает **центр/область влияния условной струи**, не реальный профиль скоростей; без скорости, `ρ`, `p` нельзя доказать баланс импульса или реальную пробивную способность. Нельзя встраивать эту поправку в уже существующее `carrier.py` так, чтобы незаметно изменить численные результаты v0.7.

## G. Задача C5: матрица α по состояниям

Из уже существующего `PlaneResult.cell_mass_kg_s` брать **массовый расход топлива**, а не массу в объёме. Для v0.7 отдельно выводить `suspended_cell_mass_kg_s` и плёнки, в качестве газофазного/условно участвующего в смешении топлива — **взвесь**, и никогда не добавлять плёнку в знаменатель молча.

```text
α_total(z,b) = G_air,total(z,b) / (L0 * G_fuel,eligible(z,b))
α_mixed(z,b) = G_air,mixed(z,b) / (L0 * G_fuel,eligible(z,b))
α_integral(z)= Σ_b G_air,total(z,b)/(L0*Σ_b G_fuel,eligible(z,b))
```

`L0` задаётся явно, с единицами и provenance, неизвестное значение блокирует только α. Все расчёты используют **идентичные z, ячейки и физический θ**; запретить простое совмещение несовпадающих индексов. Нулевое топливо → маска «нет топлива»/NaN; нулевой воздух при положительном топливе → α=0. Топливо в плёнке и невовлечённый воздух имеют собственные матрицы и отчётные статусы. Условно «вовлечённый» α не есть химический коэффициент реагирующего облака; не применять пороги пламени/температуру как физически доказанный результат.

Для ускорения допускается кэширование **унитарных пространственных влияний**, матриц по `z`, с инвалидацией только зависимых ключей. Для quasi `G_f(z,t)` меняется по давлениям соответствующих шагов; воздух либо постоянен по явно выбранному режиму, либо задан своим временным рядом (последнее отдельный будущий режим). Составной 6×140 лист обхода по разным временам не имеет единого мгновенного баланса.

## H. Критерии математической приёмки и независимые тесты

1. Одномерный эталон Диденко совпадает в пределах `1e-10` для долей/накопления (`0.25→1.0`), `α=0.65→2.6` при согласованном `L0 G_fuel`; ошибки/опечатки PDF **не** закреплять в fixture.
2. `G_total=G_fixed+G_distributed+G_unassigned`; при пустом списке отверстий остаток не исчезает; после добавления явного отверстия расход/остаток меняются **только** в разрешённом режиме.
3. Сумма всех `W` и фаз на каждом z и границах равна заданному расходу; интегралы площадей кольца и 1D↔2D сумма проверены, в том числе **неравные радиальные площади** и `θ`-periodicity.
4. Равномерный поток + топливная матрица с одинаковой плотностью расхода по площади → одинаковый α в топливных ячейках; неравное топливо → правильный покомпонентный α, правильный глобальный α, не среднее 840 α.
5. Три явно построенные взаимодействия (попутное/встречное/под прямым углом), контроль отсутствия влияния при `K=0`, симметрии, перестановки источников, `P=0`, перехода `θ=359°↔1°`, разной ширины/оси/ориентации внутренних и наружных стенок.
6. Вычисление не зависит от набора ручных сечений или их порядка, если они являются только наблюдаемыми точками; проверить сходимость по `Δℓ`, angular/radial quadrature и ширинам ядер без потери массы.
7. Неподдержанные обратные/рециркуляционные режимы не дают положительный фиктивный поток, NaN «успешный» α или скрытое обрезание. Проблемы должны иметь диагностируемый статус.
8. В архивных проектах/режимах v0.5–v0.7 все 36 угловых весов и 140 топливных расходов без изменения; старые численные результаты побайтно/в заданных допусках равны baseline.

## I. Программа дальнейшей калибровки (без реализации CFD сейчас)

Сохранить интерфейс `AirJetLaw(parameters, provenance, validity_range)`. При появлении совместного Fluent air+fuel: извлекать для нескольких осевых сечений **интегралы осевого расхода воздуха по тем же ячейкам** (или физически эквивалентные контрольные величины), положение/ширину струй, интегралы статусов смешения — если определимы. Сопоставлять их с численным решением при одинаковых граничных условиях; выбирать train/holdout и оценивать неидентифицируемость `P,K,spread,E(z)`. Не подбирать один набор коэффициентов к единственному выходному сечению и не объявлять красивую карту доказательством.
