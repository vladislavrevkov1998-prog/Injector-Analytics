# Графики v0.4.1

На вкладке 04 основная и split области имеют собственные настройки «Оси…»: выбор эпюры (для двойной Y — своей оси), min/max X/Y, шаг основных и промежуточных делений. Нулевой шаг означает автоматические основные / отсутствие промежуточных делений. Для защиты отклика допускается до 500 интервалов на ось. Настройки относятся к текущему представлению, исходные данные не меняются. Изменение данных/набора эпюр сбрасывает их; возврат Ctrl + средняя кнопка восстанавливает исходный диапазон.

- Наведение: прицел и координаты. Двойной ЛКМ: точка на ближайшей кривой, до 10 на область. ЛКМ + ПКМ: удалить точки.
- Средняя кнопка + выделение: масштаб участка. Ctrl + средняя кнопка или R: исходный масштаб.
- Нажмите и удерживайте ЛКМ, затем перемещайте мышь: появится наклонная вспомогательная прямая через ближайшую точку кривой. При движении меняются наклон и уравнение `y = k x + b`; вертикальная прямая имеет вид `x = c`. Отпускание фиксирует линию. До 10 прямых **на эпюру**; Delete удаляет наклонные прямые области. Обычный короткий щелчок линию не создаёт. Наклонные прямые не считаются исходными данными при добавлении точек/сравнении.
- В split загрузите JSON и выберите «Эпюры», «Матрица» или «Суммарное поле». Используются собственные параметры, плотность, сетка и координаты второго проекта; подробные поля рассчитываются в worker. Для Excel/CSV доступны эпюры исходных числовых столбцов.

## Точечный link

Включите split, выведите эпюры в обеих областях. Нажмите пустой кружок справа от нужной основной эпюры, затем щёлкните нужный график справа. За курсором следует пунктирная стрелка, после выбора остаётся сплошная. Esc отменяет незавершённый выбор. Нажатие и перетаскивание кружка с отпусканием над целью также создаёт связь.

Каждая эпюра имеет одного партнёра; новая связь заменяет прежнюю для этих эпюр. Можно связать разные R и разные листы/колонки Excel. Сопоставляется **первая серия** каждой эпюры. X должен быть строго монотонным, без повторов, с общим диапазоном; возрастающий и убывающий порядок допустимы. Заголовки таблицы должны явно указывать совместимые единицы. Если единицы X неизвестны, пользователь отвечает за численное соответствие координат; разные явно известные единицы X блокируются. Для X имена angle_deg/theta_deg и обозначения [°]/[deg]/[град] означают градусы; остальные единицы распознаются буквально. Автоматического перевода градусов/радиан и других единиц нет.

Масштаб X синхронизируется в обе стороны; Y — при совпадении единиц. При фиксации точки на одном графике на втором ставится точка **с тем же X и его собственным Y**. Для промежуточного X используется линейная интерполяция, без экстраполяции и перехода через NaN-пропуски. Если там нет значения или достигнут лимит точек, дополнительная точка не ставится. Очистка точек синхронна. Наведение показывает `ΔY = Y здесь − Y link`; положительное — зелёным, отрицательное — красным. При разных единицах выводится Y партнёра без разности.

Наведите курсор на середину стрелки: появится «+». Нажмите и выберите «Кривая связи»: откроется зависимость `Ysplit(Yосновн)`, линейная аппроксимация с уравнением, коэффициентом Pearson r и R². Используется объединение исходных X в общей области с линейной интерполяцией. Из-за интерполяции эти точки не являются независимой статистической выборкой: p-value и доказательство причинности не заявляются. Для постоянной первой кривой наклон/Pearson не определены; при постоянной второй r/R² — N/A. Разные единицы Y блокируют эту аппроксимацию. В том же меню можно удалить link.

Связи действуют для текущих отображаемых эпюр: смена данных, сечения или набора графиков удаляет затронутые связи. Скрытие split сохраняет данные. Стрелки являются элементами интерфейса и не входят в PNG отдельного графика. Кривые связи — описательное сравнение; физическая идентификация остаётся исключительно fuel→fuel.
