Дата: 17.10.2026. Опорная версия — **v0.4.1, e3703a2**. На момент работы
`origin/main` — **c02766f**, прежняя v0.5.1 с отдельной MeasurementSession.
По прямому запросу пользователя восстановлено дерево v0.4.1, затем добавлен

## Выполненный сценарий

1. «Настройки» из меню или шестерёнки 02: чекбокс «Квазистационарный» открывает
   окно режима. Кнопка рядом повторно открывает его. Без галочки работает
   прежний стационарный расчёт. Переключение не стирает применённые настройки.
2. Привязка форсунки к коллектору находится в общей таблице 02, после расхода
   в режиме. Имена регистрозависимы. Пустая привязка использует общий коллектор.
3. В окне режима задаются постоянный Δt, t₀, первый угол, направление обхода,
   каналы давления и их единицы/физический вид. Число шагов равно окружной сетке.
   Импорт XLSX/CSV имеет явное сопоставление столбцов. Никакие T не требуются.
4. F5/«Рассчитать сечения» на 04 использует выбранный режим. Для каждого z
   столбец i получает вклады всех влияющих форсунок при давлениях шага i.
   Все радиальные ячейки столбца относятся к одному времени. Эпюры построены
   именно из полученной матрицы, без усреднения давления за весь обход.
5. Подробное поле — полное мгновенное сечение. Нижний ползунок имеет ровно N
   исходных временных положений, показывает t/угол/давления/баланс и обновляет
   поле во время перетаскивания. Накопленная матрица при этом не изменяется.
6. Настройки хранятся в проекте и отдельном **`.quasi.json`** с другим внутренним
   `format`. Открытие такого файла как проекта отклоняется. Переносимые привязки
   применяются явно вместе с настройками одной операцией Undo/Redo.
7. Инструкция доступна в окне режима и в [QUASISTATIONARY_GUIDE.md](QUASISTATIONARY_GUIDE.md).

«Накопленная» означает составленную из последовательных измерений матрицу
плотности расхода, кг/(м²·с), а не интеграл массы по времени. Единого мгновенного
баланса у такой матрицы нет. Балансы проверены для каждого полного мгновенного
сечения отдельно; в отчётах у столбцов сохраняются шаг, время и перепады.

## Проверки

Среда: Linux, Python 3.12.14, PyQt5 offscreen, SciPy 1.16.3. Производственные
зависимости не изменены. Openpyxl 3.1.5 используется только как независимый
читатель XLSX в тестах. `pip check`: конфликтов нет.

На исходной v0.4.1 первый прогон дал 180 успешных проверок и одну ошибку из-за
отсутствия тестового openpyxl; после установки соответствующая проверка прошла.
Полный окончательный прогон включает все 181 прежние проверки и 29 новых:

```bash
QT_QPA_PLATFORM=offscreen MPLCONFIGDIR=/tmp/injector-mpl \
  python -B -m unittest discover -s tests -v
```

**210 тестов прошли за 107.234 с; ошибок, падений и пропусков нет.**

Новые проверки `test_quasi.py`, `test_quasi_io.py`, `test_quasi_gui.py`:

- Постоянное давление воспроизводит стационарные матрицы и аналитическое поле
  v0.4.1. Проверены 1/4/7 осевых сечений, индивидуальные z срезов, отключённые
  позиции, сохранение фиксированных 140 ID и исходных данных.
- Давление каждого шага действует на все форсунки своего коллектора. Проверено
  суммирование двух коллекторов в одной ячейке, нелинейная Q, отсутствие подмены
  на Q от среднего давления, отсутствие двойного масштабирования `curve`.
- Проверены независимые опорные давления manual/sectors и полнота сбора,
  единичные ядра при нулевом G_ref, физический Δp, разные единицы, абсолютная и
  избыточная пары, отказ при пропусках/несовместимых базах/экстраполяции без флага.
- Проверены CW/CCW и ненулевой начальный угол, взаимно однозначное соответствие
  всех времён столбцам, постоянный шаг импорта, отказ при другом числе строк.
- JSON round-trip, различение форматов, сырые данные и SHA256 импорта,
  независимое чтение XLSX/CSV отчётов, давления/расходы и балансы каждого шага.
- Настоящие Qt-действия: чекбокс/окно/инструкция, редактор коллектора, применение
  привязок, Undo/Redo, отмена черновика, F5, переключение в стационарный режим,
  независимый JSON в split и непрерывные промежуточные кадры ползунка.
- Смена времени не перестраивает ядра/матрицы/весь canvas. Растровое обновление
  сопоставлено с полной отрисовкой, включая Clip и слой подписей форсунок.

В старом тесте заголовков обнаружено, что добавление коллектора между прежними
столбцами сдвигало расход к границе viewport; автопрокрутка заголовка мешала
щелчку. Коллектор размещён после расхода в режиме, ширины уплотнены; настоящий
щелчок по обоим заголовкам снова открывает меню. Старый тест сохранён.

## Границы модели

Форма пространственных ядер фиксирована; давление меняет расходы через
существующие Q(Δp), время переноса τ=0. Воздух, температура, CFD и изменение
формы факела от давления не рассчитываются. В split подробное поле проекта
показывает явно подписанный шаг 0; матрицы/эпюры учитывают его режим. Регрессия
параметров v0.4.1 остаётся стационарной и при включённом новом режиме предлагает
переключиться в стационарный. Накопленная матрица не выдаётся за мгновенное поле.
