# v0.1.3.dev0 — реализация и проверка

Этот отчёт фиксирует состояние `edb3827`. Последующее увеличение одиночного
превью до 400×400 и подготовка v0.2 описаны в `V0.2_PREPARATION.md`.

Кандидат на базе v0.1.2 (`8631c6f`). Исходные 16 тестов прошли до изменений.
Физическая модель, ориентация секторов, фиксированные позиции и независимые
измеренные расходы сохранены. Методики v0.2 не реализовывались.

## Использование

- Ctrl+Z отменяет одно редактирование или целую вставку/групповую операцию.
  Ctrl+Y и Ctrl+Shift+Z повторяют; история ограничена 100 операциями.
  Открытие или создание проекта сбрасывает историю.
- Одно скопированное значение заполняет все выделенные редактируемые ячейки.
  TSV вставляется прямоугольником от текущей ячейки. Защищённые ячейки
  пропускаются; выход за таблицу игнорируется; неверная вставка откатывается целиком.
- Превью рядом с секторами строит только выбранный источник при z=0.
  Последовательные сигналы одной вставки объединяются через Qt event loop.
  Полярная эпюра — относительная интенсивность, не геометрическая граница.
- Цветовые карты: Auto или Manual min/max; Saturate ограничивает цвет,
  Clip to range делает значения вне включительного диапазона прозрачными.
  Общая Auto-шкала использует все четыре z отдельно для каждого вида карты.
  Manual задаёт одинаковые пределы для всех z. Шкала не относится к линейным
  окружным графикам или размеру полярных эпюр.
- Правки физических исходных данных требуют F5; сохранённые результаты и
  графики очищаются, чтобы нельзя было экспортировать устаревшее поле.
  Цветовые правки сохраняют готовые расчётные матрицы.
- Первый просмотр вида строит график; возврат к нему использует кэш.
  PNG-экспорт явно строит также неактивные виды.

## Проверки

Linux, Python 3.12, PyQt5 5.15.11, NumPy 2.5.4, Matplotlib 3.11.2.
Qt работал в режиме `offscreen`.

```bash
python -m venv /workspace/.venvs/injector-analytics
/workspace/.venvs/injector-analytics/bin/python -m pip install -r requirements.txt
QT_QPA_PLATFORM=offscreen MPLCONFIGDIR=/tmp/injector-mpl \
  /workspace/.venvs/injector-analytics/bin/python -B -m unittest discover -s tests -v
```

Результат: **39 тестов прошли, 0 ошибок, 0 пропусков**, около 11,6 с.
Проверены массовый баланс, неизменность CSV при разных шкалах, старые JSON,
сохранение новых цветовых параметров, сохранение точности неизменённых чисел,
прозрачность и видимость стенок/ID, Undo/Redo таблиц и групповых действий,
горячие клавиши, один источник в превью, ленивый кэш, MathText и настоящий
фоновый расчёт с возвратом результатов в интерфейс.

Дополнительно `batch_run.py` выполнен на полном демонстрационном проекте
со 140 форсунками и Manual/Clip to range, пределы 0..0.05 кг/(м²·с).
Созданы и проверены **16 PNG и CSV** в `/tmp/injector-v013-batch`.
Расход 1400 кг/ч; невязки четырёх сечений:
`−6.423e−15`, `+8.565e−16`, `+7.994e−15`, `0`.
Временные артефакты не включены в репозиторий.

## Скорость переключения

Демонстрационный `examples/demo_project_140.json`, 140 источников, четыре z,
активна вкладка консервативной матрицы, контуры и ID включены, окно показано
в offscreen. Расчёт исключён из таймера, Qt/Matplotlib painting включён.
Первое сечение прогрето; замерены первые посещения 1,2,3 и восемь переключений
0,1,2,3,0,1,2,3.

| Медиана | v0.1.2 | v0.1.3.dev0 |
|---|---:|---:|
| Первые посещения других сечений | 1460 мс | 261 мс |
| Повторные переключения | 1431 мс | 3.96 мс |

Первые посещения ускорены примерно в 5,6 раза, повторные — примерно в 360 раз
в этой среде. v0.1.2 при каждом переключении строит четыре вида; кандидат
строит один активный вид при первом посещении и затем переключает готовый
canvas. Это не замер скорости физического расчёта и не гарантия Windows-времени.

```bash
# Новая реализация
QT_QPA_PLATFORM=offscreen /workspace/.venvs/injector-analytics/bin/python -B \
  tools/benchmark_switching.py

# Исходники базы для сравнения, без изменения текущего checkout
mkdir -p /tmp/injector-v012-source
set -o pipefail
git archive 8631c6f src | tar -x -C /tmp/injector-v012-source
QT_QPA_PLATFORM=offscreen /workspace/.venvs/injector-analytics/bin/python -B \
  tools/benchmark_switching.py --source /tmp/injector-v012-source/src/fuelfield/gui.py
```

## Ограничения

- Windows, Spyder, системный буфер обмена Excel и оконная отрисовка на реальном
  экране здесь не проверены. Qt-буфер и TSV, горячие клавиши и рисование проверены
  автоматически на Linux offscreen; кандидат не объявляется Windows-релизом.
- Кэш сохраняет до 16 Matplotlib canvases (4 вида × 4 сечения); первый просмотр
  нового вида всё ещё требует отрисовки. Смена представления освобождает кэш.
- Превью одной форсунки использует 240×240 декартовых отсчётов с увеличенной
  областью просмотра; очень узкие кольца могут быть недостаточно разрешены.
  Оно не заменяет консервативный баланс и не участвует в числовом экспорте.
- Дополнительные поля шкалы позволяют новой версии читать старые JSON;
  открытие нового JSON старым приложением v0.1.2 не гарантируется.
- История Undo/Redo хранится в памяти сеанса, не в JSON.

Для обычного оконного запуска на машине с графической средой:
`python main.py`. В облаке без экрана для автоматических проверок используется
`QT_QPA_PLATFORM=offscreen`; веб-превью этому desktop-приложению не требуется.
