## Что реализовано

| Требование | Реализация и проверка |
|---|---|
| Совпадающие концы не расходятся при drag | Неудачный пробный шаг оставляет последний согласованный кадр. Один завершённый жест — один Undo. Проверки реальными жестами и независимые ограничения. |
| Касательность дуга–дуга | Прежняя направленная подгонка дополнена ограниченным biarc-построением для двух свободных дуг. Сохраняются внешние концы/касательные и все исходные связи; фиксированные объекты не перемещаются. Несовместимость диагностируется. |
| Номера концов и ввод углов | Серые «1»/«2» не перехватывают мышь и не меняют fit сцены. Текстовые списки углов/составов групп принимают `;`, включая замену одиночного исходного числа. |
| Последовательный перенос | Одни расходные пакеты проходят внутренние станции. Нет повторного построения свободного факела на каждом z и удаления вкладов при `R_форсунки < Rmin(z)`. |
| Стенка и вся подача | Первый контакт численной траектории с аналитической линией/дугой переводит 100% её веса в отдельную плёнку. Далее — точная стенка, заданная положительная скорость. Плёнка не возвращается во взвесь при расширении. |
| Контроль массы/импульса | Три фазовые матрицы и отдельные потоки импульса [Н]. Внутри + две плёнки = введённая подача; вне стенок и старый wall-bound в новой модели равны нулю. |
| Параметры неизвестны | Новое окно не выдумывает измеренные значения. Требуются явные скорости/τ/полуширина; отдельная кнопка подставляет маркированный учебный пресет. Атомарное применение, отмена, Undo/Redo. |
| Квазистационар | Единичные влияния построены из тех же траекторий/фаз. Давление меняет расход; ползунок использует кэш. Составная матрица не получает фиктивный единый мгновенный баланс. |
| Экспорт и совместимость | CSV/XLSX разделяют взвесь и плёнки, сохраняют настройки и поток импульса. Новая модель требует project schema 3; legacy сохраняет schema 2. |
| Источники и схемы | Агент изучил реальное исходное ядро, предоставленную монографию и доступные исходники OpenFOAM; подготовил условные схемы, затем они проверены и использованы для замыкания. См. отдельный обзор и журнал доступа. |

## Численные доказательства

- Цилиндр: точное аналитическое поле носителя, постоянный объёмный расход,
  аналитическая релаксация капель и независимый поток силы `G Δv` [Н].
- Сужение/расширение: постоянный интегральный расход носителя, межэлементная
  непрерывность нормального потока, непроницаемость сеточной стенки. Проверены
  кривые стенки, вертикальные касательные, единицы и масштабирование.
- Первый контакт: линии и круговые дуги, неверная ветвь квадратичного уравнения,
  касание, выход/вход на начальной границе и узкое место между двумя внутренними
  концами шага. Независимое сравнение 1000 широких двухдуговых шагов: 715 контактов,
  максимальное отличие доли шага от dense-bracket + Brent — `4.58·10⁻¹⁵`.
- Все 36 измеренных интегральных долей сохраняются при разных разрешённых
  размерах квадратуры, включая 36/108/180 узлов. Нормировка общего расхода
  сама по себе не считается доказательством правильных секторных долей.
- Увеличение числа поясов/угловых ячеек и смена измерительного отсчёта не
  меняют частицы. Добавление выходных плоскостей не меняет общий результат
  и seeded OU-историю при неизменной физической области.
- Контрольная цилиндрическая точка z=37.3 мм: максимум ошибки XY относительно
  аналитики при шагах 8/4/2/1 мм равен соответственно
  `0.00788076 / 0.00193683 / 0.000501656 / 0.000115823 мм`.
- S-профиль при фиксированной радиальной сетке носителя: уменьшение шага
  4 → 1 → 0.25 → 0.125 мм уменьшает отличия радиуса и времени от самого мелкого
  результата. При 0.25 мм отличие радиуса 0.0364 мм, времени `8.24·10⁻⁷ с`.
  Это численная сходимость выбранного замыкания, не валидация реального течения.
- Положительный рабочий источник за выходом теперь отвергается до пропуска
  «сечение перед срезом». Обычный источник внутри ЖТ ещё не введён перед своим
  срезом. Форсунка с нулевым расходом не создаёт фиктивный расход и траектории.

Синтетический S-профиль, 140 позиций / 139 с ненулевой подачей, 5 сечений:
`G = 0.3110008070700416 кг/с`. На выходе 160 мм:

| Фаза | Расход, кг/с |
|---|---:|
| Взвесь | 0.01135951754983041 |
| Внутренняя плёнка | 0.15432922604353888 |
| Наружная плёнка | 0.1453120634766723 |

Невязка массы не более `1.8·10⁻¹⁶`, импульсного учёта — порядка `10⁻¹⁵`.
Большая доля плёнки — результат этих учебных предположений, не предсказание
для испытанного изделия. Суммы плёнок не выдаются за концентрацию взвеси.

## Быстродействие и интерфейс

Контрольный замер сделан отдельно от тестовых процессов, с одним потоком BLAS,
на реальном QThread по F5, активном таймере Qt 5 мс и реальных RGBA-пикселях
виджета. Скрытые таймеры не отключались ради улучшения цифр.

| Действие | Измерено |
|---|---:|
| Пользовательский проект: явный учебный перенос, 4 z, F5 + первый рисунок | 3.484 с |
| S-профиль, 5 z: первый / повторный F5 + рисунок | 3.409 / 2.851 с |
| 140 шагов / 2 коллектора / 5 z: подготовка + первый рисунок | 19.535 с |
| Повторное переключение 4 видов, медиана / p95 | 12.161 / 15.543 мс |
| Ползунок времени, медиана / p95 / максимум | 37.914 / 40.030 / 40.177 мс |
| Изменившиеся пиксели поля при шаге 0 → 35 | 8394 |
| Полные перерисовки canvas при этих шагах ползунка | 0 |

Во время расчётного worker p95 интервала Qt был 7.5–8.6 мс; максимальный
измеренный интервал 168.7 мс. Первое создание фигуры остаётся заметным:
первый визит в виды занял 0.38–1.07 с; финальная отрисовка после worker —
0.48–0.69 с, максимальная пауза таймера с учётом неё — 503 мс. Поэтому
утверждение «никаких подвисаний» не делается. Повторные виды используют
те же canvas/художники; составные матрицы от навигации не меняются.
Цифры относятся к этой Linux-среде, не к любому пользовательскому ПК.

Визуально просмотрены окно параметров, матрица, поле, эпюры, поле с ползунком
и инструкции со схемами. Скриншоты — `docs/images/v0.7/ui-*.png` и
`transport-guide-*.png`. Горизонтальная прокрутка справки отсутствует;
обязательные поля и кнопки доступны, численные параметры прокручиваются.

## Границы результата

Это не реализованная RANS/LES-модель турбулентных струй. Носитель — заданный
осесимметричный безвихревой несжимаемый поток; τ, OU-флуктуации и полный
захват в плёнку — явные замыкания без экспериментальной калибровки. Оси
источников пока +z; наклоны объектов остаются метаданными. Тела/следы,
воздух, отрыв, испарение, дробление, повторный срыв и температура не решаются.

Реакции носителя/стенки записаны в учёте потока импульса топлива, но поле
носителя от них не изменяется. Малая невязка не доказывает полного
двухстороннего сохранения импульса камеры. Квазистационарный режим не
переносит предысторию давления с задержкой; manifest показывает время
пролёта относительно dt. Быстрые изменения требуют нестационарной модели.

Прочитаны доступные фрагменты монографии пользователя и указанные исходники
OpenFOAM. Недоступные научные статьи не выдаются за прочитанные; ограничение
доступа и вторичные ссылки перечислены в [обзоре](V0.7_LITERATURE_REVIEW.md).
Ни научные источники, ни сохранение массы не выбирают однозначно контактное
замыкание и реальные скорости при отсутствии исходных данных.

Полная матрица включает плёнку в граничных ячейках. XY-поле — сглаженная
интерполяция тех же траекторий; интеграл по его пикселям приближённый и не
используется для баланса. Старый регрессионный подбор для новой физики
явно заблокирован: его h(z)/затухание не являются параметрами нового оператора.
