# v0.5.2 — исправления интерфейса и графики давления

Версия остаётся **0.5.2**, как запросил пользователь. База исправлений:
`main` **8d6541a**, принятая первоначальная сборка квазистационарного режима
(PR #14), физическая основа — v0.4.1. Ветка: `codex/v0.5.2-fixes`.
Исходный `examples/demo_project_user_field.json`, давления демонстрационного
примера и производственные зависимости не изменены.

## Что исправлено

1. Превью форсунки строится на вкладке 02; правки на других вкладках больше не
   запускают его скрытый расчёт и полную отрисовку. Пока пользователь выделяет
   ячейки, превью отложено до окончания серии выделений. Пустые скрытые canvas
   при сбросе результатов также не отрисовываются заранее.
2. Выход из числового поля без изменения значения больше не перечитывает всю
   таблицу 140 форсунок и не сериализует её. Исправлен повторный расчёт графика
   Дитякина после единственного изменения плотности. При квазистационарном
   режиме таблица не вычисляет ненужные расходы от стационарного целевого Δp.
3. Устранён вызов `blit` из `draw_event`, приводивший к повторному входу в
   обработчик Qt-paint во время полного кадра. Ползунок обновляет сохранённый
   слой изображения; подписи/контуры остаются поверх поля. На каждом кадре
   используются готовые балансы, не пересчитывается вся мгновенная матрица.
4. Исключены повторное построение шкалы и лишние копии массива. При `nearest`
   цвет назначается после приведения скалярного изображения к экранному размеру,
   вместо промежуточного разворачивания всех 720² значений в RGBA. Численные
   поля, диапазон шкалы и выбранные значения не изменяются; пиксели сравнены
   с полным RGBA-рендером, включая Manual/Clip и масштаб экрана 200%.
5. Справа от таблицы давления добавлен **один график на коллектор**. Графики
   обновляются после ручного ввода, вставки, импорта и загрузки JSON. Для
   абсолютной/избыточной пары видны топливо, газ в той же единице и полученный
   Δp. Пропуски/незаконченный ввод образуют разрывы. Изменения черновика не
   применяются к проекту автоматически. Закрытое окно не обновляет графики.
   Для нескольких коллекторов есть прокрутка, ширина областей регулируется.

Под полем показаны давление, фактический расход и изменение расхода относительно
шага 0. Интенсивность меняется при фиксированных контурах форсунок. В исходном
синтетическом примере колебания невелики; шаги **0 и 70 имеют одинаковые
давления и одинаковые поля**. Для видимого сравнения используйте 0 и 35.
Данные и цвета не усиливаются искусственно; Manual/Saturate может скрывать
малые изменения насыщением, поэтому для проверки полезен Auto.

## Проверки

Исходный прогон: **210 тестов, 111.097 с, OK**. Окончательный полный прогон:
**217 тестов, 100.106 с, OK, без пропусков**. Отдельная проверка реальных
пикселей при масштабе экрана **200%: 1 тест, 4.434 с, OK**.
Новые проверки охватывают:

- изменения реальных пикселей QWidget, а не только массива или счётчика кадров;
- правильный кадр после resize и возврата на вкладку, совпадение с полным
  рендером RGBA; прежние проверки Clip и сохранения матрицы;
- расположение графиков справа, число графиков при добавлении/удалении
  коллектора, обновление кривой, пакетную вставку одним обновлением, разрывы
  и конверсию единиц газ/топливо;
- отсутствие работы закрытых графиков/скрытого превью, отсутствие чтения всей
  таблицы при неизменённом контроле и однократный refresh после изменения ρ.

Прежний тест массового выделения теперь явно выбирает вкладку 02: именно на
ней превью должно вычисляться. Проверки числа расчётов, задержки серии,
повторного использования и размера отдельного поля сохранены.

Команды:

```bash
QT_QPA_PLATFORM=offscreen MPLCONFIGDIR=/tmp/injector-mpl \
  python -B -m unittest discover -s tests -v
QT_QPA_PLATFORM=offscreen QT_SCALE_FACTOR=2 MPLCONFIGDIR=/tmp/injector-mpl \
  python -B -m unittest discover -s tests -p test_quasi_gui.py -k native_widget -v
```

Linux, Python 3.12.14, PyQt5 offscreen. `pip check` — без конфликтов.
Windows/Spyder по прежнему указанию пользователя не проверялись.

## Сравнительное быстродействие

`tools/benchmark_v052_ui.py` запускался последовательно на неизменённом
`8d6541a` и исправленном исходном коде, отдельно от тестов. Использован
`demo_project_user_field.json`: 140 позиций, 6×140 ячеек, четыре z, поле 720²,
исходный синтетический режим двух коллекторов. Штатные таймеры не отключались.
Для ползунка и вкладок — реальные QTest действия; выход из контрола проверялся
сигналом Qt `editingFinished`, отдельно от полной правки физического параметра.

| Действие | До | После |
|---|---:|---:|
| Ползунок, 60 шагов после 5 прогревочных: медиана / p95 | 47.044 / 51.833 мс | **28.278 / 32.235 мс** |
| Максимальное время показанного кадра | 53.264 мс | **33.904 мс** |
| Повторные переключения всех четырёх вкладок: медиана / p95 | 9.460 / 12.007 мс | 9.084 / 10.304 мс |
| Неизменённый числовой контрол: медиана / p95 | 10.453 / 11.572 мс | **0.263 / 0.533 мс** |
| Максимальная пауза Qt после физической правки на 01 | 147.522 мс | **53.014 мс** |
| Полные перерисовки canvas за серию кадров ползунка | 0 | 0 |

Синхронная фиксация физической правки остаётся сопоставимой: 46.534 / 47.535 мс.
Отложенная скрытая отрисовка после неё устранена. Первые посещения вкладок
требуют вывода содержимого: например, на 03 — около 59 мс. Первое открытие 02
отвечает за 15.613 мс; превью появляется после паузы выбора. Это время отклика
вкладки, а не время готовности превью. Расчёт с первым показом результата —
4.232 с. Нулевые паузы при холодном построении сложного рисунка не заявляются.

100 изменений таблицы давления сгруппированы в **одну** отрисовку двух графиков
за **188.725 мс**, включая таймер 120 мс. Смена времени изменила 4510 пикселей
реального Qt-виджета между шагами 0/35. После ползунка, переключений и неизменённых
контролов проверены идентичность результатов, точное равенство матриц и проекта;
исходный файл не перезаписывался. Тайминги относятся к этой облачной машине.
