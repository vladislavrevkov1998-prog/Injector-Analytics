# Validation v0.5.0

База — принятая v0.4.1, `main` **e3703a2** (merge #11). До изменений: **181 тест, 145.589 с**, без ошибок. Ветка `codex/v0.5`. Исходный `examples/demo_project_user_field.json` и зависимости не изменены. Руководство: [V0.5_GUIDE.md](V0.5_GUIDE.md).

## Замечания пользователя

1. Все дробные редакторы используют значащие разряды без заполняющих нулей. При вводе цифры внутри полной дробной части удаляется последний незначащий ноль. Проверены настоящие нажатия в QLineEdit, точка и запятая; значащие цифры не отбрасываются. Шаги 0.001/0.0001 сохранены. Неизменённый редактор не округляет полный исходный float.
2. Вкладка 04 переключает X между градусами и окружными ячейками: `x=θ·N/360`. При N=140 ось 0…140, шаг 2.571428571°. Замыкающая точка N совпадает с 0. Переключение не вызывает физический пересчёт. Split-проект использует тот же физический отсчёт X; CSV/XLSX позволяет явно выбрать отсчёт углов файла. Неугловые X не преобразуются. Link синхронизирует точки по выбранному X.
3. На вкладке 01 задаются ноль и направление увеличения угла. Физические координаты форсунок остаются неизменными, таблица 02 переводит углы в выбранный отсчёт. Контрольная сетка и подписи используют этот отсчёт; требуется F5. Старые JSON получают 0°/+1. Положительный Clock и 36 местных секторов сохраняют прежнее физическое направление.

## Реализация согласованного v0.5

- Независимые от Qt `measurement.py`, `transient.py`, `measurement_io.py`: версия сессии, сырые данные, шесть одновременных T на остановку, собственные окна и фактические углы, радиусы реальных датчиков, несколько коллекторов и топливно-газовый перепад.
- Проверяются физический вид и единицы давления, согласованный reference_id для избыточных давлений, положительный Δp, качество, строгий порядок времени, покрытие окон и заданных задержек. Между недостоверными отсчётами интерполяция запрещена. Единицы и сдвиг часов задаются явно, исходные строки не меняются.
- Единичные консервативные пространственные влияния K строятся до умножения на G. Сумма весов с потерями за стенками равна 1 для достигнутых плоскости источников; нулевой G_ref не служит делителем. Проверяется соответствие кэша геометрии/сетке/z.
- `curve` использует абсолютное Q один раз, `manual/sectors` — исходный расход × Q(P)/Q(Pref). Корневой закон не подставляется. Интегрируется Q(Δp(t)), а не Q от среднего Δp. Экспериментальная кривая: точные трапеции с разбиением по пересечениям узлов Q; Дитякин: адаптивная квадратура с rtol и оценкой численной ошибки.
- Выход — средний за окно q по контрольной ячейке, содержащей фактическую координату датчика. Это дискретизация существующей консервативной модели, не footprint реальной термопары. Экспорт содержит координаты, границы ячейки и площадь. Разрешение можно увеличивать для проверки сходимости.
- Вкладка 05: импорт с выбором листа/столбцов, редактирование, проверка, worker, прогресс/отмена, повторное использование K, эпюры q/T с разными Y, составные матрицы, история давления и мгновенный снимок. Паспорт сворачивается при просмотре результатов; на 1280×800 остаётся место шести графикам.
- Сессия включается в JSON проекта одной операцией Undo/Redo. CSV/XLSX сохраняет исходную T, давление/качество, временные окна, 140 расходов, задержки, балансы отдельных снимков и воспроизводимый паспорт/снимок проекта. Отменённый/неудачный расчёт сохраняет предыдущий полный результат. После изменения входов графики/экспорт явно относятся к предыдущему снимку до пересчёта.
- Синтетические JSON/CSV на 140 остановок помечены как синтетические. Два коллектора используют Δp и отдельные абсолютные давления топлива/газа. Один температурный отсчёт отсутствует. Температуры не вычисляются из q.

## Границы и интерпретация

- Температура остаётся независимым наблюдением. Fuel→T, CFD, воздух и подбор задержки из геометрии не реализуются. Регрессия v0.4 остаётся fuel→fuel.
- K зафиксировано на весь протокол; изменения формы факела от давления не моделируются. Дискретизация/геометрия и экспериментальная неопределённость не исчезают от малого численного rtol. Паспортная неопределённость и отклик термопары сохраняются в метаданных, статистическое распространение этих погрешностей не вводится.
- По умолчанию τ=0. Общая/индивидуальная/точечная задержка — независимый заданный вход. Баланс полного снимка проверяется при его собственном t, τ=0; для составной матрицы из разных окон единый мгновенный глобальный баланс не определён.
- Балансы автоматически проверяются на границах/серединах окон и узлах давления, а также для каждого запрошенного мгновенного снимка. Пространственная нормировка обеспечивает консервативность при любом допустимом векторе расходов.
- Углы могут повторяться в разные времена. Отображение эпюр сортирует только копию по углу; составные матрицы и экспорт сохраняют порядок протокола. Обход может быть неполным; все шесть радиусов обязательны, пустые/недостоверные температуры не превращаются в нули.
- Дубли X после смены отсчёта внешней замкнутой таблицы (0° и 360°) остаются исходными точками; неоднозначный X блокирует link по прежним правилам. Это не повод усреднять или удалять исходные данные.
- Редкие предупреждения tight_layout возможны при промежуточных изменениях размера окна; окончательная компоновка проверена визуально. Windows/Spyder не проверялись по указанию пользователя.
