# v0.8.5 — совместные поля топлива, воздуха и расходного α

На вкладке **04** одним F5 рассчитываются топливные поля, воздушные поля и
отношения α в режиме, выбранном в **Настройки → Испытания и расстановка**.
Воздух не меняет физическое ядро топлива: 36 измеренных секторных объёмов,
140 ID и перенос топлива v0.7 сохраняются. Старые проекты открываются с
выключенным воздухом. Температура, реакция и CFD не рассчитываются.

## Начало работы

1. Откройте проект и проверьте геометрию, топливные расходы и настройки режима.
2. На **01 → Шаблоны форсунок → Воздух** задайте параметры завихрителя для
   охлаждаемой/неохлаждаемой форсунки, если они известны для данного типа.
   Вкладка **Топливо** сохраняет прежние параметры факела. Пустой расход —
   неизвестное значение; расход топлива никогда не копируется в воздух.
3. На 04 откройте **Баланс воздуха…**, введите суммарный расход через КС [кг/с]
   и L0 [кг воздуха/кг топлива]. Включите воздух явно. L0=0 означает
   «неизвестен»: воздушный расчёт доступен, α остаётся неопределённым.
4. Добавьте завихрители, отверстия/вставки или свяжите источники с объектами
   Sketcher. Если воздушные шаблоны заданы, отсутствующие завихрители появляются
   в черновике по типам установленных форсунок. Известные ручные источники
   сохраняются. Проверьте индивидуальные правки и неизвестный остаток.
5. Укажите направления, ширины и закон вовлечения, затем **Применить**.
   До применения изменения принадлежат черновику. После воздушной правки
   готовое топливо сохраняется, но воздушные результаты требуют нового F5.
6. Нажмите **Рассчитать поля (F5)**. В общем списке **Величина** выберите
   топливо, плотность/расход воздуха, ядро, вовлечённый/обратный воздух,
   **α_total** либо **α_mixed**. Отдельного окна воздушных матриц нет.

## Матрица, подробное поле и эпюры на 04

Воздух и α показываются в той же круговой сетке, что и топливо: физические
радиусы ячеек, измерительный угловой отсчёт из 01, отметки положений гребёнки,
окружности размещения и контуры форсунок. Флажки контуров/номеров управляют
подписями. Масштаб цвета Auto/Manual, общая шкала всех z и Saturate/Clip
работают для выбранной величины. Неопределённый α показан серым.

**Матрица** и **Окружные эпюры радиальных уровней** используют одну выбранную
величину. Можно выбирать R, число графиков и колонок, градусы или номера ячеек.
В стационарном режиме все ячейки относятся к одному состоянию. В quasi
матрица и эпюры составляются по проходу гребёнки: разные угловые столбцы
соответствуют разным временам и давлениям. Единого мгновенного α сечения
у такой составной матрицы нет.

**Подробное поле** для топлива сохраняет прежнюю непрерывную визуализацию;
для воздуха/α эта вкладка показывает мгновенную круговую матрицу. В quasi
существующий ползунок времени выбирает реальный шаг, время и давления.
Воздушные входы v0.8.5 стационарны: с данным воздухом соотносится топливо
выбранного шага. Изменение времени не меняет накопленную матрицу и не запускает
повторный расчёт топливных влияний. Отдельного выбора «стационарный» в окне
воздуха нет. Режим меняется только в общих настройках.

Полярные эпюры 36 секторов каждой форсунки относятся к исходному топливу;
эта вкладка недоступна при выбранной воздушной величине. Окружные эпюры α
доступны на последней вкладке. Сравнение второго проекта использует его
собственные воздушные данные; при их отсутствии показывает сообщение,
а не подставляет топливные числа под подписью α.

## Что означают все общие настройки баланса

| Настройка | Назначение и единицы |
|---|---|
| Включить воздух / `enabled` | Явно включает расчёт подсистемы при F5. Выключение не удаляет введённые данные. |
| G воздуха КС / `total_kg_s` | Известный суммарный расход через КС, **кг/с**. Это бюджет всех каналов, а не расход одного ФУ/завихрителя. |
| L0 / `l0` | Явный стехиометрический массовый коэффициент, кг воздуха/кг топлива. 0/неизвестен оставляет α неопределённым; G воздуха при этом рассчитывается. |
| Распределение / `distribution` | `uniform` распределяет расход пропорционально площадям ячеек; `directed` использует заданные пространственные ядра каждого источника. Равные радиальные высоты не означают равные площади. |
| Взаимодействие / `interaction_strength`, 0…10 | Безразмерная интенсивность эмпирического поворота направлений соседних струй. 0 — независимые направления. Это не коэффициент физического баланса импульса. |
| Принимаю гипотезу сходных условий / `area_hypothesis_confirmed` | Явное согласие распределять остаток по F или CdF. По одной площади при неизвестных гидравлических условиях физический расход не определяется. |
| Доля остатка для F / `area_allocation_fraction`, 0…1 | Какую часть свободного остатка распределить между area/effective_area. 0.5 оставляет половину такого остатка неизвестной. |
| Доли групп, % / Расходы групп, кг/с | Единицы ползунков/числовых полей категорий. Категория — завихрители, отверстия, вставки, охлаждение, прочие. |
| Ползунок или число группы | Меняет только переменные источники выбранной категории, переводя их в fraction и сохраняя относительные доли. При отсутствии прежних долей назначает равные доли. Заданные fixed G не масштабирует. |
| Цветная диаграмма | Показывает назначенные категории и неизвестный остаток. Нажатие доли выделяет строки категории, наведение показывает расход и процент. |
| Редактировать заданные G | Явно разрешает изменение защищённых известных расходов, в том числе при переходе к шаблону. До включения измеренные значения защищены. |
| Добавить источник | Создаёт новый самостоятельный элемент с неизвестным расходом. |
| Добавить завихрители | Создаёт недостающие связи с существующими ID 1…140; использует воздушный шаблон типа или оставляет расход неизвестным. Не дублирует уже существующий завихритель. |
| Связать с геометрией | Добавляет источник для выбранного отверстия/вставки/форсунки геометрии. Координаты следуют связанному объекту. |
| Удалить выбранные | Удаляет выбранные воздушные записи из черновика; топливные форсунки и объекты Sketcher сохраняются. |
| Сброс к шаблону | Возвращает выбранные параметры наследуемого завихрителя к шаблону типа. Защищённый G требует явного разрешения правки. |
| Параметры JSON… | Доступ к внутреннему шагу, горизонту траекторий, масштабу взаимодействия, точкам/порциям вовлечения и сохраняемым метаданным. Изменения проходят ту же проверку. |
| Применить / Закрыть | Применить сохраняет валидный черновик одной командой истории проекта; закрытие без применения оставляет проект прежним. |

Фиксированные G и фиксированные доли резервируются прежде, чем распределяется
остаток. При превышении общего бюджета применение блокируется: исходные G
не нормируются автоматически. Неназначенный воздух остаётся видимым остатком
и не создаёт искусственного источника или струи.

## Все столбцы источников

| Столбец / ключ | Смысл |
|---|---|
| ID / `id` | Устойчивый непустой уникальный идентификатор воздушного источника. Это не расход и не номер ячейки. |
| Тип / `kind` | swirler, hole, insert, cooling, other — категория источника/диаграммы. Завихритель относится к воздуху вокруг одного распылителя. |
| Включён / `enabled` | Учитывать этот источник. Отключённая запись сохраняет параметры, но не добавляет расход. |
| Группа / `group` | Пользовательская метка группы; не создаёт дополнительной массы и не заменяет физическую связь. |
| ID форсунки / `nozzle_id` | Связь завихрителя с существующей топливной позицией 1…140. Координаты берутся от этой форсунки; второе списание того же канала запрещено. |
| ID геометрии / `object_id` | Связь с объектом отверстия/вставки/форсунки Sketcher. Удалённая/повторная связь диагностируется. |
| Параметры / `template_mode` | `manual` — ручные значения; `inherit` — воздушный шаблон установленного типа форсунки плюс индивидуальные air_overrides. Старые источники остаются ручными. |
| Метод / `method` | `fixed` — заданный G; `fraction` — доля от G КС; `area` — остаток по F; `effective_area` — по CdF; `unknown` — расход неизвестен и не входит в матрицу. |
| G / `flow_kg_s` | Массовый расход **одного** источника в кг/с для fixed. Пусто — неизвестен. Ноль — явно заданный нулевой расход. |
| Доля / `share` | Доля суммарного G КС для fraction, **0…1**, не проценты таблицы. Например, .1 = 10%. |
| F / `area_mm2` | Проходная площадь в мм²; для area/effective_area нужна положительная величина. Площадь не является расходом. |
| Cd / `cd` | Явный положительный коэффициент расхода для effective_area. Не выводится из P и не подставляется молча. |
| z / `z_mm` | Осевое положение входа в мм. |
| R / `radius_mm` | Радиус входа в мм, внутри локального тракта. |
| θ / `theta_deg` | **Физический** угол от +X против часовой стрелки, в градусах. Измерительный отсчёт задаётся отдельно на 01. |
| Стенка / `wall` | free, inner, outer. При привязке к стенке координата/нормаль проверяются по локальному профилю; направленное отверстие должно смотреть в тракт. |
| dz, dr, dθ / `direction` | Пространственное направление в локальном цилиндрическом базисе. +dz — по оси, +dr — наружу, +dθ — против ЧС. Вектор нормируется; его длина не является скоростью. Нулевой вектор запрещён. |
| Пробивная способность / `penetration_factor` | Неотрицательный **безразмерный** параметр эмпирического поворота/взаимодействия. Не скорость, давление, Н или физический импульс. |
| Ядро / `kernel` | directed — локальное направленное ядро; uniform — по площади всего сечения; wall — пристенная пелена, требующая касательного направления. |
| σR / `sigma_r_mm` | Начальная радиальная ширина в мм. 0 — предельная узкая поддержка ячейки, а не отрицательная/вымышленная ширина. |
| σθ / `sigma_theta_deg` | Начальная окружная ширина в градусах, с периодичностью по θ. |
| Расширение / `spread_mm_per_mm` | Неотрицательное приращение ширины [мм] на единицу пройденного пути [мм]; угловая добавка получается через локальный радиус. |
| Вовлечение / `mixed_fraction` | Начальная условно вовлечённая доля одного G, **0…1**. Остальная часть относится к ядру. Это доля той же массы, а не дополнительный расход. |
| Длина вовлечения / `mixing_length_mm` | Положительная длина роста E по пройденному пути. Пусто — начальная доля постоянна, если не задан отдельный закон E(z). |
| Доверие / `confidence` | Метка происхождения/доверия к данным. На сам расход и коэффициенты математики не влияет. |

Для nozzle_id/object_id связанные координаты показаны в таблице только для
чтения: изменяйте их в исходной геометрии, а не второй независимой копией.
Метод, тип, ядро, стенка и режим наследования имеют списки внутри ячеек.

Таблица поддерживает выделение отдельных/прямоугольных ячеек, Ctrl+C, Ctrl+V
и табличный TSV из Excel. Одно вставляемое значение заполняет все выделенные
редактируемые ячейки. Несколько строк/колонок вставляются блоком от текущей
ячейки. Вставка проверяется целиком; при ошибке откатывается весь блок.
Защищённые G и связанные координаты не обходятся через буфер обмена.

## Дополнительные параметры JSON и закон вовлечения

| Параметр | Значение |
|---|---|
| `interaction_length_mm` | Положительный эмпирический масштаб длины для накопления поворота соседних направлений, мм. Не время пролёта. |
| `step_mm` | Положительный внутренний шаг по **длине траектории**, мм. Не расстояние между наблюдаемыми z. Проверяйте сходимость его уменьшением. |
| `max_path_mm` | Конечный горизонт по длине пути, мм. Недостижение сечения к его концу не доказывает отсутствие реального воздуха. Слишком мелкий шаг/большой горизонт блокируются лимитом памяти. |
| `entrainment_points` | Таблица `[[z_mm,E],…]`: z строго возрастает, E не убывает и лежит в 0…1. Между точками применяется интерполяция. |
| `entrainment_stages` | Альтернатива точкам: список порций одного источника. Не задавайте оба закона одновременно. |
| Порция: `id` | Уникальный идентификатор порции данного источника. |
| Порция: `z_start_mm`, `z_end_mm` | Начало/конец вовлечения порции в мм, конец не меньше начала. При равенстве — ступень. В пределах этих z порция вовлекается линейно. |
| Порция: `fraction` | Неотрицательная доля исходного G; сумма всех порций равна 1. Наблюдение нескольких сечений не создаёт повторной массы. |
| `provenance` | Словарь источника данных, условий/единиц и комментариев. Сохраняется в проекте и экспорте. |
| `schema_version` | Версия воздушной записи, сейчас 1. Не версия геометрии или экспериментального протокола. |
| `air_overrides` | Список ключей параметров завихрителя, которые берутся из индивидуальной записи вместо шаблона типа. `direction` переопределяется целиком. |

Для простого постоянного E достаточно mixed_fraction. При mixing_length_mm
используется рост к 1 по пройденному пути. При явно заданных точках или порциях
используется соответствующий осевой закон. Диденко в примере — арифметический
1D эталон с синтетическим пространственным продолжением. Это не уникальное
экспериментально подтверждённое 3D поле.
Подробные формулы: [V0.8_IMPLEMENTED_MODEL.md](V0.8_IMPLEMENTED_MODEL.md).

## Воздушные потоки в Sketcher

На **01 → Профили ЖТ** выберите режим:

- **Геометрия** — зелёная обводка, прежнее редактирование профиля/объектов.
- **Воздушные потоки** — синяя обводка; перетаскивание, создание, таблицы,
  геометрические размеры/связи и Undo геометрии заблокированы. Панорама,
  масштаб, выбор источника и переключение проекции остаются доступны.

Выберите воздушный элемент в списке или нажмите его линию. Редактируйте G,
метод, направление, ширины, расширение, пробивную способность, вовлечение,
ядро/стенку в панели справа. Изменения обновляют локальный черновик и картинку;
**Применить воздух** сохраняет их одной командой, а **Отменить воздушный
черновик** возвращает сохранённые значения. Кнопка **Для выбранного объекта**
создаёт недостающий источник у выбранного отверстия/вставки/форсунки.
Баланс и расширенные законы E(z) открываются отдельной кнопкой панели.

Синие траектории/стрелки для известных расходов взяты из того же эмпирического
расчёта, что и матрицы. Показаны проекции пространственного направления:
меридиональная z,R и окружная X,Y. Если проекция нулевая, ⊙/⊗ отмечают знак
перпендикулярной компоненты; полный нормированный [dz,dr,dθ] указан числами.
Это направления, не измеренные скорости. Жёлтый пунктир при неизвестном G или
выключенной модели — **только направление ввода**, не результирующая струя.

Пунктирные границы — ±1σ заданного ядра с расширением вдоль реального пути,
обрезанные границами тракта, а не физическая резкая поверхность воздуха.
Можно показать √2σ условно смешанного воздуха и скрыть остальные источники.
Для uniform пунктир показывает границы всего тракта. Пристенное ядро следует
выбранной стенке. Изменения параметров сразу меняют эти линии, не геометрию ЖТ.

## α и экспорт

`α=G_air/(L0×G_fuel_eligible)`. Интегральный α — **отношение сумм расходов**,
а не среднее локальных α. В v0.7 знаменатель включает только взвесь: стеночные
плёнки сохраняются в топливной диагностике и исключены из α. При отсутствии
топлива, неизвестном L0 или неподдержанном обратном/многократном пересечении
значения маскируются. При положительном топливе и нулевом воздухе α=0.

Кнопки **CSV: матрицы**, **XLSX: эпюры**, **PNG: текущее/все z** на 04
работают с выбранной величиной. Для воздуха CSV/XLSX сохраняют все воздушные
и α-матрицы, фазовые данные, источники и единицы. В подробном мгновенном виде
экспортируется выбранный реальный шаг с временем/давлениями; в матрице/эпюрах —
составная карта с собственными временами/давлениями столбцов. Отсутствующий
мгновенный α составного сечения не подменяется числом.

CSV создаёт комплект таблиц и JSON-манифест: переносите их вместе. XLSX
содержит длинные численные таблицы по z/R/θ, из которых строятся эпюры,
и листы происхождения/ограничений. Маски α записываются явно, неопределённые
числа — пустыми ячейками. Длинные JSON делятся на нумерованные части для Excel.
PNG сохраняет выбранную круговую карту, мгновенную карту и окружные эпюры;
топливные «розы» не экспортируются под воздушной подписью.

## Три темы и история графиков

**Настройки → Тема приложения**:
**Стандартная светлая**, **Светлая с зелёными акцентами**, **Тёмная с акцентами**.
Выбор сохраняется между запусками в QSettings, не в JSON проекта, и не запускает
расчёт. Выбранные, невыбранные и недоступные вкладки имеют отдельные читаемые
состояния. Палитра графиков и Sketcher переключается вместе с Qt-интерфейсом.

На 04 Ctrl+Z/Ctrl+Y относятся только к графикам: точки, наклонные линии,
масштаб, оси и связи. Пустая графическая история не отменяет исходные данные.
На Sketcher в воздушном режиме Undo геометрии заблокирован. Переключитесь
в геометрический режим, чтобы редактировать/отменять геометрические шаги.
Наклонная линия на графике появляется при удержании ЛКМ; один drag — одна
команда истории. Esc/выход из canvas отменяют незавершённую линию.

## Примеры и ограничения

- `demo_project_v08_air_synthetic.json`: 140 различных синтетических расходов
  завихрителей, косые отверстия, охлаждение и неизвестный остаток.
- `demo_project_v08_didenko_reference.json`: арифметический 1D эталон Диденко;
  пространственное продолжение и L0 помечены синтетическими.

Воздух задан независимой стационарной подсистемой даже в quasi: задержка его
пульсаций/обратное влияние на топливо не решаются. Сильные встречные/обратные
струи, вовлечение, σ/P и взаимодействие требуют отдельной калибровки. Модель
не является CFD или расчётом истинного состава реагирующей смеси.
Проверки новой поставки: [V0.8.5_VALIDATION.md](V0.8.5_VALIDATION.md).
Численные проверки исходной v0.8: [V0.8_VALIDATION.md](V0.8_VALIDATION.md).
Windows/Spyder считаются проверенными только при наличии протокола запуска.
