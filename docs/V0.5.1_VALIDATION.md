# Validation v0.5.1 — инструкция вкладки 05

База — `main` **437a57a** (merge #12, принятая v0.5.0). Ветка `codex/v0.5.1-guide`. В базе пройден полный набор из 212 тестов, см. [V0.5_VALIDATION.md](V0.5_VALIDATION.md). Перед правками отдельно выполнены 14 тестов `test_v05_ui.py`: 12.584 с, без ошибок.

## Выполнено

- Кнопка «Инструкция» справа вверху вкладки 05, как в идентификации параметров. Открывает отдельное немодальное окно с прокручиваемым текстом; повторное нажатие возвращает то же окно, закрытие позволяет открыть его заново.
- [Подробная инструкция](V0.5_MEASUREMENT_SESSION_GUIDE.md): все поля паспорта/политики времени, 18 столбцов остановок, 8 столбцов давления, 3 столбца коллекторов; обязательность, единицы, пропуски, начальные заготовки и ручные флаги достоверности. Разобраны импорт/mapping, физические виды давления, синхронизация часов и задержки, кнопки, пять видов результатов, взаимодействие с графиками и все листы отчёта.
- В начале дан прямой ответ: результат сессии автоматически не передаётся на 04 и не меняет форсунки. Отдельно описаны входные JSON, включение сессии в проект с последующим Ctrl+S, необходимость повторного включения правок, сохранение рассчитанных массивов в отчёте и повторный расчёт после открытия.
- Список «Раздел» содержит 20 переходов к основным разделам и видам результатов. Заголовок выбранного раздела размещается вверху страницы. Окно не требует горизонтальной прокрутки при исходном размере 1000×720. Кнопка закрытия подписана по-русски.
- Справка остаётся доступной во время worker. Расчётные ядра, схемы данных, зависимости и исходный пользовательский проект не изменены.

## Проверки

```bash
QT_QPA_PLATFORM=offscreen MPLCONFIGDIR=/tmp/injector-mpl PYTHONFAULTHANDLER=1 \
python -B -m unittest discover -s tests -p test_v05_ui.py -v
```

После добавления кнопки и инструкции: **14 тестов прошли за 10.669 с**, без пропусков и ошибок. Математические проверки полностью не повторялись: изменение относится к встроенной справке; расчётное ядро не менялось.

Дополнительно выполнены настоящие QTest-щелчки по кнопке и «Закрыть», повторное открытие, проверка немодальности, чтения русского Markdown и переходов по всем 20 разделам. На размерах основного окна 1280×800, 1480×930, 1920×1080 кнопка видна и помещается внутри вкладки. Окно справки проверено визуально: текст и таблицы переносятся, доступна вертикальная прокрутка.

Сценарий на `examples/demo_project_user_field.json`: рассчитаны четыре стационарных сечения; открыта справка, загружен явно синтетический протокол с постоянным Δp=30 кгс/см² и рассчитана сессия 6×140; справка открывалась во время worker. После расчёта сессии сохранены идентичность списка основных результатов, точное равенство их массивов и JSON-снимка проекта, SHA256 исходного файла. Это также проверяет описанное в инструкции отсутствие автоматической передачи результата на вкладку 04. Протокол/T в этом сценарии тестовые, не новые измерения.

Linux offscreen, Python 3.12.14, PyQt5; Windows/Spyder не проверялись по указанию пользователя. Новые замеры скорости математического расчёта не выполнялись; прежние замеры v0.5 остаются в [отчёте](V0.5_LATENCY.json).
