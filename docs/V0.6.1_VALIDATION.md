# v0.6.1 — исправления Sketcher и проверка

Основа: принятая v0.6, `main` **cf8c754** (merge PR #19, исходники равны
98dc820). Ветка исправлений: `codex/v0.6.1-fixes`. Математика распределения

`examples/demo_project_user_field.json` сохранён побайтно.

## Замечания пользователя

| Замечание | Изменение и проверка |
|---|---|
| Дуга исчезает при вводе параметров | Радиус изменяет центр при неподвижных концах. Координаты конца согласуют окружность. Некорректная геометрия рисуется красным черновиком; проверены ввод 10/3, вставка всех параметров с единицами, исправление черновика. |
| Перетаскивание не срабатывает | Область захвата маркера увеличена; проверяются настоящие press/move/release с первого щелчка, без предварительного выбора строки. |
| Все три точки сдвигаются и возвращаются | Убран групповой Qt-перенос выделенных маркеров. Каждый кадр строится от снимка нажатия; raw, таблица и маркеры согласованы, commit один при отпускании. |
| Импорт XLSX | Выбор листа, строк, z/R, единиц, стенки, предпросмотр; проверка всех строк до изменения проекта, один Undo. Формулы без результата и ошибочная первая строка не пропускаются. |
| Свободная дуга | Конец следует за курсором с сохранением углового размаха; квадрат центра и сама линия переносят всю дугу. Центр не ограничен биссектрисой. |
| Сечения меняют геометрию | «Расчётные сечения» меняют только координаты расчёта. Выходная метка автоматическая. Перенос прежнего выходного среза создаёт новый на физическом выходе, стенки остаются прежними. |
| Читаемые ID | Новые примитивы ВН№/НР№/ОП№, сечения S№, объекты H№/I№/первая буква типа, группы G№. Существующие ID не переименовываются, ссылки и неизвестные поля сохраняются. |
| Выползание окна 04 | Причина — зависимость размеров layout от первого показа и cached Figure, отдельной анимации в коде не было. Стеки графиков имеют устойчивый sizeHint; split-canvas помещается в панель. Проверены первые/повторные визиты и геометрия окна при font13/1280×720. |
| Ветка и TXT | Обновлены отдельные TXT и ZIP с чистым runtime-кодом. Точный commit исходников и SHA-256 записаны в восстановителе. В комплект встроены три инструкции UI. |

Дополнительно: адаптивная сетка, координаты курсора, выделение выбранной дуги,
различимые маркеры центра/концов, подсказки, два ряда инструментов, отмена
незавершённого построения через Esc и явный сброс черновика. Разбиение примитива
перепривязывает объект ко второй половине, если его z находится на ней.

## Проверки

Linux, Python 3.12, PyQt5 offscreen. `pip check` — без конфликтов.
Windows и Spyder отдельно не проверялись по ранее согласованному ограничению.

- Baseline v0.6: 78 профильных тестов за 23.246 с, OK. Предыдущий полный
  прогон исходной v0.6 — 305 тестов; см. [отчёт v0.6](V0.6_VALIDATION.md).
- На исходной версии новые 6 сценариев дуг воспроизвели 5 отказов и 1 ошибку.
- Независимая математика: 12 проверок, включая обе ориентации и большие/малые
  дуги, полукруг, неподвижный противоположный конец, единицы mm/cm/m.
- Независимый UI: 10 проверок реальными Qt-событиями. Общее соединение двух
  дуг в мм/см остаётся точным, Undo/Redo атомарны. Ожидаемая координата
  вычисляется из фактически отправленных целых пикселей через mapToScene;
  сравнение delta с rtol=0, atol=1e-9, без произвольного допуска курсора.
- XLSX, разделение сечений/геометрии, ID, привязки и восстановление черновика:
  13 проверок. Отдельно проверено отсутствие скрытого пропуска первой строки.
- Чистый TXT: 3 проверки — воспроизводимые байты ZIP, контроль всех файлов
  до записи, отказ при изменённой установленной копии, восстановление в папку
  с пробелами/кириллицей, запуск UI и трёх справок без Git/docs/examples.
- Первый полный прогон: 343 теста за 286.458 с, один отказ старого UI-теста
  давления: фиксированных 160 мс не хватило на 120-мс debounce и очередь Qt.
  Изолированно тот же тест прошёл за 1.912 с. Теперь он ждёт реального обновления
  с пределом 1 с и проверяет ровно одно обновление, все данные/число графиков/
  отсутствие применения черновика. Таймер программы не изменён.
- Повторный прогон: 343 теста за 308.758 с; аналогичный фиксированный интервал
  сработал нестабильно в соседнем тесте пакетной вставки давлений. Все три теста
  отложенных графиков переведены на ожидание счётчика обновлений с тем же
  ограничением 1 с; они вместе проходят (3 теста, 6.503 с). Проверки одного
  обновления на пакет, пропусков, единиц и отсутствия скрытой отрисовки сохранены.
- Итоговый полный прогон: **343 теста за 236.865 с, OK, без пропусков**.

## Отклик

с настоящими событиями мыши и отрисовкой Qt; таймеры не отключаются.
Это результаты облачного Linux, не гарантия таких же чисел на другом ПК.

## UI и ограничения

[Sketcher 1280×800](images/v0.6.1/sketcher_1280_font10.png) ·
[крупный шрифт](images/v0.6.1/sketcher_1280_font13.png).
Проверены оба ряда панели, поля, кнопки, splitter и статус. Последние столбцы
широкой таблицы доступны через горизонтальную прокрутку. При изменении размера
окна масштаб сохраняется; кнопка «Вписать» показывает весь профиль.

Для одновременных шести графиков, split и шрифта 13 на высоте 720 пикселей
Matplotlib может сообщать о нехватке места для подписей. Виджеты остаются внутри
панелей; для читаемых подписей выберите меньше графиков либо увеличьте окно.

Свободное движение не отменяет требования однозначного положительного R(z).
Невозможная стенка сохраняется на экране как черновик; расчёт/JSON используют
последнее применённое состояние. Полный CAD-решатель ограничений, сплайны,
воздух, перенос капель/плёнки, α и температура в эту корректировку не входят.
Инструкция обновлена в [V0.6_GUIDE.md](V0.6_GUIDE.md) и в кнопке Sketcher.
