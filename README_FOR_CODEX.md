# Перенос проекта Fuel Field Pilot в Codex

В комплекте — исходный **работающий пилот v0.1.2**, 16 исходных тестов и согласованное ТЗ следующих версий. **Новая функциональность из ТЗ НЕ реализована этим архивом.**

1. Распакуй архив в папку проекта на Windows, запусти `python -m unittest discover -s tests -v`.
2. Открой эту папку в VS Code с расширением Codex либо запусти Codex CLI в корне проекта.
3. Дай Codex инструкцию из `CODEX_START.md`.
4. Выполняй этапы A, B, C отдельными коммитами/версиями.
5. Для облачного Codex требуется подготовленная среда/репозиторий с разрешённым доступом; при ограничениях предприятия не передавай туда закрытые данные без согласования.

Документы:
- `docs/ROADMAP_v0.2.md` — постановка 16 требований и критерии приёмки.
- `docs/PARAMETERS_AND_UNITS.md` — значения действующих параметров и единицы.
- `MODEL_SPEC.md` — исходная физическая модель v0.1.2.
- `AGENTS.md` — инструкции для Codex.
