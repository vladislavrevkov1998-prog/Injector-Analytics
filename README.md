# Injector Analytics — Fuel Field Pilot

Инженерный пилот моделирования распределения топлива за 140 форсунками кольцевого фронтового устройства.

## Состояние

- Рабочая исходная версия: **v0.1.2** (Python / PyQt5 / NumPy / Matplotlib).
- Новые пожелания v0.1.3–v0.3 — **техническое задание, а не реализованная функциональность**.
- В частности: экспериментальные расходные характеристики из произвольного количества пар (Δp, Q), расчёт по проверенной методике Дитякина; метод Тейлора отложен.
- Шкала: режимы Saturate и Clip to range (вне ручного диапазона цвета становятся прозрачными без изменения численных данных).

## Старт с Codex

Откройте репозиторий в Codex и прочитайте `AGENTS.md`, `CODEX_START.md` и `docs/ROADMAP_v0.2.md`.

Сначала проверить исходные тесты и реализовать стадию A (скорость интерфейса, Undo/Redo, редактирование, динамическое превью, работа шкал). Не пытаться внедрить всю дорожную карту одновременно.

## Физические ограничения

Секторные объёмы измерены на Δp = 2,5 кгс/см²; расход измерен отдельно на Δp = 30 кгс/см². Сумма собранных объёмов может не отражать полный расход. Нормированный угол распыла и пространственное распределение не равнозначны измеренной концентрации топлива без скоростей капель.

Все изменения фиксировать тестами, сохранять совместимость старых JSON, не объявлять модель Дитякина реализованной без проверки исходных уравнений.
