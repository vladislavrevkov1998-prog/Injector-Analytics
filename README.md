# Injector Analytics — Fuel Field Pilot v0.2.0

Пилот моделирования распределения топлива за 140 форсунками кольцевого
фронтового устройства. Версия v0.2 включает экспериментальные и расчётные
расходные характеристики, пересчёт давления, типы форсунок и шаблоны геометрии.
Расчёт Дитякина реализован для простой форсунки с короткой камерой и круглыми
тангенциальными входами по оригинальной монографии 1977 года.

## Возможности

- Несколько типов распылителей, произвольные измеренные точки Δp,Q,
  кусочно-линейная интерполяция, CSV/XLSX-импорт, график и CSV-экспорт.
- Расчётная характеристика Дитякина: геометрия распылителя, вязкость и плотность,
  переменные Aₑ, φ, потери и μ; график Q(Δp), проверка применимости.
- Независимое измерение расхода при 30 кгс/см² и секторные объёмы при 2,5;
  пересчёт по характеристике на целевое давление, полнота сбора и предупреждения.
- Переключение кг/ч ↔ л/мин нажатием на заголовок расхода; каноническое хранение
  кг/ч. Источник, давление и измеренный/расчётный статус видны в таблице.
- Охлаждаемая/неохлаждаемая форсунки, редактируемые шаблоны, индивидуальные
  overrides и reset. Ввод R_сопла вместо Rc0; старые JSON читаются без изменения
  результатов исходной модели.
- Manual/auto-follow: смещаются текущая и последующие позиции только своего
  ряда, включая отключённые. Отключение само по себе не меняет координаты.
- Undo/Redo, массовая вставка, одиночное превью 400×400, кэш графиков,
  Auto/Manual/Saturate/Clip to range, MathText, количественный CSV и PNG-экспорт.

Уравнения, коэффициенты, численное интегрирование потерь и поддерживаемая
область описаны в [методике Дитякина](docs/DITYAKIN_METHOD.md).

## Запуск

Из корня репозитория в Python-среде:

```bash
python -m pip install -r requirements.txt
python main.py
```

Для численного расчёта и PNG без Qt-окна:

```bash
python batch_run.py examples/demo_project_v02.json --out results
python batch_run.py examples/demo_project_dityakin.json --out results_dityakin
```

Пример v0.2 содержит **условные демонстрационные точки, не экспериментальные
данные**. Начальные геометрические шаблоны тоже демонстрационные; пользователь
задаёт собственные параметры. Обычный пример `demo_project_140.json` сохранён
для проверки совместимости v0.1.2.
Пример `demo_project_dityakin.json` также демонстрационный: его размеры и
вязкость не представляют конкретное испытанное изделие.

В облаке тесты запускаются с `QT_QPA_PLATFORM=offscreen`:

```bash
QT_QPA_PLATFORM=offscreen python -B -m unittest discover -s tests -v
```

Windows/Spyder по указанию пользователя пока не входят в обязательные проверки.

## Работа с v0.2

На вкладке 01 откройте редактор типов, создайте тип, введите или импортируйте
пары Δp,Q, укажите единицы и нажмите «Применить характеристику». Тип с ссылками
из форсунок удалить нельзя: сначала переназначьте ссылки. На вкладке 02 выделите
нужные строки и назначьте распылитель.

Для расчётного типа выберите «Дитякин — простая короткая форсунка», задайте
гидравлические размеры и кинематическую вязкость [мм²/с]. Плотность берётся из
проекта. Диапазон давления в редакторе задаёт график; расход в каждом режиме
вычисляется решением гидравлических уравнений. Статус показывает Aₑ, φ, μ,
Re и потери. Эти размеры задаются отдельно от параметров поля орошения.

Источник расхода:

- `manual`: независимое измерение при указанном давлении;
- `sectors`: оценка по собранным 36 объёмам, времени, плотности и η;
- `curve`: расход непосредственно по назначенной характеристике.

Новый проект начинает работу в режиме пересчёта; старый JSON загружается в Legacy.
Для нового пересчёта выберите «Пересчёт по характеристикам» и целевой перепад.
Legacy-режим сохраняет прежний расчёт старых проектов; в нём давление и η не
пересчитываются. Неизвестная η явно принимается равной 1 в новом режиме.
Экстраполяция запрещена по умолчанию; разрешение включается отдельным флажком
с видимым предупреждением. Измеренные расходы и исходные сектора сохраняются.
Для Дитякина выход за область геометрии/коэффициентов или отсутствие
критического сечения в слишком коротком сопле отклоняются; флажок
экспериментальной экстраполяции эти ограничения не отменяет.

Тип форсунки назначается выбранным позициям. Сброс overrides включает
наследование из шаблона; последующая индивидуальная правка снова создаёт override.
Смена шаблона обновляет только унаследованные параметры. Начальная плёнка:
[R_сопла−h0, R_сопла], Rc0=R_сопла−h0/2.

## Проверки и ограничения

[Отчёт v0.2](docs/V0.2_VALIDATION.md): 93 теста, совместимость с независимыми
эталонными полями v0.1.2, Qt-сценарии, массовый баланс и пакетный экспорт.
Численная реализация Дитякина проверена независимым RK4-расчётом. Отсчёты
коэффициентов с графиков книги приближённые; инженерная модель требует
сопоставления с измерениями конкретного распылителя.
[Подготовительный план](docs/V0.2_PREPARATION.md) сохранён как исторический документ.

q(x,y,z) — плотность массового расхода [кг/(м²·с)], не концентрация [кг/м³].
Контрольная матрица по умолчанию 6×140; подробная карта и одиночное превью не
заменяют её интегральный баланс. Баланс включает потоки за обе стенки.
Сумма собранных секторных объёмов может не отражать полный расход.
